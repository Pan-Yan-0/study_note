# MG-LoRA · Kaggle 运行说明（问题二、问题三）

## 一、上传前的准备

| 项 | 怎么做 |
|---|---|
| 代码 | Kaggle → New Notebook → File → Import Notebook，选 `mg_lora_kaggle.ipynb` |
| 数据 | Add Input 选你上传的 `mathcompetition` 数据集。代码会在 `/kaggle/input` 下自动找「附件2 / 附件3 / 附件4」目录，**自动跳过「未对齐版本」和附件1** |
| BERT | 二选一：右侧 Settings 打开 **Internet**（自动下载 bert-base-uncased）；或 Add Input → Models 搜 `bert-base-uncased`（transformers 版本） |
| GPU | Accelerator 选 **GPU T4 x2**（只用一块）或 P100 |
| 环境 | 用 Kaggle 默认镜像（torch 2.5.1、transformers 4.47），**不需要 pip install** |

## 二、运行顺序

1. **冒烟测试**：第一个代码单元把 `SMOKE = False` 改成 `SMOKE = True`，点 Run All，大约 5–10 分钟。重点看日志里这几行：
   - `附件2 结构`：train/valid/test 都在，`text_bert` 是 `(N, 3, 50)`、`audio` 是 `(N, 50, 74)`
   - `att3 结构`：30 条；`att4 结构`：20 条
   - `数据审计`：附件3 的 `A_samples_with_missing`、`V_samples_with_missing` 应该接近 30；train/valid 应该很少
   - 最后一行出现 `全部完成`
2. **全量运行**：改回 `SMOKE = False`，右上角 **Save Version → Save & Run All (Commit)**，在后台跑，关掉浏览器也没关系。T4 上预计 2–3 小时。这是按 3395 条训练集估算的，没有实测过。
3. 跑完在该 Version 的 **Output** 里下载 `outputs.zip` 发给我，我据此写论文。

**中途超时或断了**：把这次 Version 的输出加回来当 Input（Add Input → Your Work → 这个 Notebook），再跑一次。已经训练好的检查点会被自动复制过来，训练会跳过。

**数据没找到**：日志会列出找到的所有特征文件。在配置单元里手动填 `ATT2_PATH`、`ATT3_PATH` 或 `ATT4_PATH`，文件或文件夹都可以。

**想缩短时间**：把 `SEEDS_MAIN` 改成 3 个种子，或者 `RUN_ABLATIONS=False`。

## 三、方法：两篇各取了什么，新加了什么

| 来源 | 保留下来的 | 改掉 / 新加的 |
|---|---|---|
| 第二篇（v3） | LoRA 微调 BERT 做文本主干；PM 规则面板（7 种模态组合 × 3 个比例 × 头中尾 = 63 档）；规则层思路（中性判定、强度校准） | 规则不直接上线：先在验证集上按**源视频分组做 5 折交叉验证**，折外有增益、且在缺失面板上不变差才启用。另加一条「极性—强度一致性」规则（题面规定 0 只属于中性） |
| 第一篇（LDSD） | 语言主导；「完整视角教师 → 缺失视角学生」的自蒸馏；训练时模拟**连续段**缺失（M1）；让补偿进入推理路径（M4 的思想） | 缺失模拟**不再参考附件3**，只按题面文字定义构造（一个或多个模态、1–4 段互不重叠的连续区间、总比例 U(0.05, 0.9)、小概率整路缺失）。「补洞」改成表示层对齐教师的低秩补偿 |
| 新的 | **缺失门控 LoRA**：阶段一只用完整输入训练；阶段二冻结阶段一，在 BERT 的 q/v 和融合层中各加一组低秩补偿，用门控 g 控制，g 由缺失描述量 φ（每个模态的缺失比例、最长缺口、有无缺失）算出，且无缺失时 g 恒为 0 | 完整输入时模型与阶段一**逐位相同**（等价性检查里会实测）。这就在结构上消除了第二篇 A–E 实验看到的「缺失样本变好、完整样本变差」的权衡 |

问题三用同一个模型：

- **精确 Shapley**：三个模态只有 8 个子集，不需要抽样近似，分类头和强度头各算一套，并检查效率性误差。
- **逐位置遮蔽重要性**：窗口宽 3。
- **证据定位**：文本证据落到原词；声学、视觉证据换算成秒和帧，并截取关键帧。
- **忠实性检验**：删除得分最高的位置，与删除随机位置、删除得分最低的位置比较。
- **稳定性检验**：给声学和视觉加噪声，看重要性排序的 Spearman 相关。

模态被「拿掉」时，是由训练过缺失的模型来打分，所以 Shapley 的各个子集取值不在分布外。

## 四、评估清单（全部自动完成）

- **完整输入**：Acc-3、macro-F1、MAE、Pearson，另有 Acc-2、Acc-5、Acc-7 和 ECE。
- **PM 面板**：63 档局部连续缺失，报告平均值和最差档。
- **LH 压力面板**：只保留部分模态，其余整路关闭，子集内再删一段。
- **SC 散点面板**：训练分布外的离散缺失，检验是不是只学会了连续段。
- **MS 多段面板**：每个被遮模态放 3 段互不重叠的短区间（21 档）。
- **扩展扫描**：缺失比例 0.1 到 1.0，看文本的「全有或全无」现象。
- **消融**（每个都和同种子的 MG-LoRA 比）：
  - 常规联合训练 joint
  - 无门控 mg_nogate
  - 无教师 mg_nokd
  - 散点训练 mg_scatter，用来检验「成段」这一约束是否必要
- **统计**：主配置 5 个种子、消融 3 个种子；报告种子配对差值及其 t 区间，另做部署种子的视频配对重抽样（1000 次）。
- **机制检查**：
  - 完整输入等价性实测
  - 门控值与缺失程度的相关
  - 附件3 覆盖性检查：事后只读缺失描述量，不参与训练或选择
- **规则层**：6 种规则组合的折外结果，同时看完整输入和 PM 面板。
- **错误归因**：
  - 按真实类别、强度大小、句长、原生缺失、主导模态、置信度分组
  - 最自信的错例（附原文）
  - 错误类型计数
- **问题三质量**：Shapley 效率误差、主导模态分布（按类别）、忠实性、稳定性、人工复核标记的查错率。
- **测试集**：只在最后评估一次，含规则前后对比和混淆矩阵。

## 六、需要你知道的几件事

1. **训练部分我这边没有实际跑过**：我的环境装不了 PyTorch。读数据、构造掩码、评估、规则、解释、证据定位、作图、报告这整条链路，我用和附件目录结构相同的合成数据测通了，模型用的是模拟预测器。训练代码是否能跑，要以你的 SMOKE 结果为准。报错的话，把 `log.txt` 或报错截图发我。
2. **数据使用**：模型、epoch、规则阈值只用验证集来选；测试集只在最后评估一次；附件3 只用于推理。
3. **附件4 的秒/帧定位**：开了 Internet 时，会用 torchaudio 自带的 MMS 强制对齐，由已知文本得到词级时间戳（首次要下载约 1.2 GB 权重）。没开 Internet 时，按词序在视频时长内均分，这只是近似。CSV 的 `timing_method` 列会写明用了哪种。文本证据不受影响，都能精确对应到原词。
4. **部署种子**：部署种子 17 是事先固定的，不按结果挑选。其他种子只用于报告波动，以及附件3 的「多种子一致率」。
