# 数学建模：2026 年“华为杯”第二十三届中国研究生数学建模竞赛 E 题

题目方向：多模态（文本、语音、视觉）情感分析。

- 问题一：从原始视频提取文本、语音、视觉特征，并在时间上对齐；
- 问题二：局部模态缺失下的鲁棒情感预测；
- 问题三：可解释的情感预测（哪个模态、哪个位置起了作用）。

本分支（`math_modeling`）只放这道题的论文、代码和结果，和仓库里其他分支无关。

## 目录

| 路径 | 内容 |
|---|---|
| `paper/` | 论文稿 PDF 两份，以及各自的 LaTeX 源码 |
| `code/` | 在 Kaggle 上运行的实验代码，v1 到 v3.2，每个目录有运行说明 |
| `results/` | 各版本的结果与结论 |
| `docs/` | 对照赛题原文的检查与 v3.1 改进计划 |

## 代码版本

每个目录里有 `.py` 和同名的 `.ipynb`：两者是同一份代码，`.ipynb` 是上传 Kaggle 用的笔记本形式（不含运行输出）。

| 目录 | 内容（摘自各版本的运行说明） | 结果文档 |
|---|---|---|
| `code/v1_MG-LoRA/` | MG-LoRA 第一版：问题二、问题三 | `results/MG-LoRA_v1v2结果与结论.md` |
| `code/v2_MG-LoRA/` | v2：单调连续门控、缺失感知的贝叶斯决策层、Mondrian 共形预测、Shapley 交互指数 | 同上 |
| `code/v3/` | v3：DeBERTa-v3-large + 集成，外加对 v2 结论的补验 | `results/v3结果与结论.md` |
| `code/v3.1/` | v3.1：DeBERTa 只用 `text_bert`，EMA，集成蒸馏，朴素零填充对照，问题三专项模型 | `results/v3.1结果与结论.md` |
| `code/v3.2/` | v3.2：大小写恢复，类别概率来源，混合集成，4 bit 量化 | `results/v3.2结果与结论.md` |

运行环境是 Kaggle（T4 或 P100 GPU，默认镜像），详细步骤见每个目录里的运行说明。
