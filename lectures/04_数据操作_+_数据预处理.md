## 笔记

### 一句话总结
张量要先看形状：reshape、拼接和广播都是在对形状做文章。Task 2 的一个 batch 是 (B, T, d) 的张量，用 mask 把补齐的位置置零。

### 关键概念与公式
- 广播规则：两个张量的形状右对齐，从最后一维往前比；每一维要么相等，要么有一个是 1；维数少的，前面缺的维按 1 算；有一维不满足就报错。
- 能广播：（1，4，3）与（4，3）。不能广播：（1，4）与（4，3）。
- `Y = Y + X` 会新建一个张量，Y 指向新的地址；`Y += X` 在原来的张量上改，Y 的地址不变。

### 形状与代码要点
1. 创建（2，3，4）的张量，reshape 成（6，4）（前两维合并）；再和另一个（6，4）的张量用 `torch.cat` 拼接：第 0 维得（12，4），第 1 维得（6，8）。
2. 用 `id()` 验证：
```python
before = id(Y)
Y = Y + X
print(id(Y) == before)   # False
before = id(Y)
Y += X
print(id(Y) == before)   # True
```
3. 动手任务：X 是 (2, 5, 3)，mask 是 (5,)，直接相乘会报错（最后一维 3 对 5）。`mask.unsqueeze(-1)` 变成 (5, 1) 后再乘，X2 的形状仍是 (2, 5, 3)，X2[0] 前 3 行保留、后 2 行为 0。改条件后 mask 是 (2, 5)，同样要 `unsqueeze(-1)` 成 (2, 5, 1)。

### 回忆题

**1. X、Y 的形状都是 (3, 4)。`torch.cat((X, Y), dim=0)` 和 `torch.cat((X, Y), dim=1)` 的结果各是什么形状？**

> `torch.cat` 的 dim 指沿着哪一维拼：dim=0 沿着第 0 维（行）拼，(3, 4) 和 (3, 4) 拼成 (6, 4)；dim=1 沿着第 1 维（列）拼，拼成 (3, 8)。

**2. 形状 (32, 12, 768) 的词元向量和形状 (32, 12) 的 attention_mask，怎样相乘才能把补齐位置的向量置零？直接相乘为什么报错？**

> 直接相乘会报错：(32, 12, 768) 和 (32, 12) 右对齐后，最后一维 768 对 12，不相等，也都不是 1。做法是先给 mask 加一维：`mask.unsqueeze(-1)` 把 (32, 12) 变成 (32, 12, 1)，再和词元向量相乘（`*` 是逐元素相乘，不是矩阵乘法）。768 对 1 时，1 被复制，补齐位置的 768 个数都乘 0。

**3. pandas 里处理缺失值的两种做法（插值、删除）各有什么代价？**

> 插值（例如用均值补全）的代价：填进去的是“编”的值，缺失的行都落在平均值上，这一列的波动被压小，看起来比真实情况更确定，也掩盖了缺失本身带的信息（缺失本身也是值得研究的课题）。删除的代价：数据规模变小，缺失不随机时还会有偏。
