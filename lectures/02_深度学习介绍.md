## 笔记

### 一句话总结
这里讲解了深度学习的各种应用，还有机器学习的一些例子，解释了监督学习、无监督学习等各种学习类型。

### 关键概念与公式
机器学习的四个组件：数据、模型、目标函数（也叫损失函数）、优化算法。

分类与回归最主要的区别就是输出：一个输出类别，一个输出数字。分类模型先给每个类别打一个分数，用 softmax 变成概率，再用 argmax 取概率最大的那个类别当作输出；回归的输出不限于 0 到 1 之间，可以是任意实数。

### 形状与代码要点


### 和 Task 2 的联系
- 数据：输入一对短语，即 text1、text2，再加上标签 label，所以是监督学习。
- 模型：利用别人训练好的模型（mDeBERTa 或 XLM-R）来微调。编码器把一对短语读成一个向量；我们再加一个线性层（分类层），把这个向量变成四个类别的分数，做四分类。
- 目标函数：交叉熵。
- 优化：AdamW，是一种梯度下降的优化方法。
- 整条线：短语对 → 编码器 → 向量 → 分类层 → 四个分数 → softmax → 四个概率 → argmax → 一个标签。
