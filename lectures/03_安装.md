### 回忆题

**1. `pip install d2l==0.17.6` 不加 `--no-deps` 时，可能改动 Kaggle 预装的哪些包？为什么有风险？**

> 我现在用的是本地环境，没有用 Kaggle。不在 Kaggle 上装 torch==1.12.0，是因为这会破坏 Kaggle 预装的环境：预装的 torchvision、torchaudio 是按预装的 torch 版本编译的，torch 换成旧版就对不上，会报错甚至崩溃；而且 torch 1.12 只支持 Python 3.7–3.10，不支持 3.11。

**2. `torch.cuda.is_available()` 返回 True 能说明什么、不能说明什么？（对照第 1 周的 env_check.py）**

> `torch.cuda.is_available()` 返回 True，只说明 torch 带 CUDA 支持、有可用的 GPU；说明不了 GPU 的型号和显存够不够，也说明不了训练能不能真正跑通。

> torch.version.cuda、torch.cuda.get_device_name(0): ('12.1', 'NVIDIA GeForce RTX 3050 Laptop GPU')
