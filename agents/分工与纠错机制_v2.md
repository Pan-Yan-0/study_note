## 2. 工作线分工

**单点写入原则**：一个路径在同一时间只有一个写入方；多端协作的工作线，**每个具体任务明确一位实现负责人（单点写入），另一位做独立审阅，修改经交接后由该任务负责人提交**。不能推 GitHub 的端将产出放进 Drive，由 Antigravity 基建对话跑完检查后提交。

### 2.2 创作线衔接（兼容现有 `codex-article` 检查）

- **不另造 `MAT-...` 编号**：保留 `codex-article` 现有的 `m-...` 编号、台账 `daily/LEDGER.md`、`GPT_RULES.md v5` 和 `check_drafts.py`（**已有**）。
- **原文入库与引用核对**：
  1. 候选论文 PDF 或 arXiv HTML 原文先放入 Drive `素材/`；素材卡示例严格区分「论文数据（`source_type: arxiv`）」与「个人实验数据（`source_type: study_note`）」，不混在同一示例里。
  2. 引用某张素材卡写短帖时，将该素材卡快照随稿存入 `codex-article`。
  3. 拟新增的 `verify_refs.py`（**待实现**）在实现并通过验收前不视为已运行检查；实现时对引文和原文先做文本归一化（`unicodedata.normalize('NFKC')`、去跨行连字符 `-\n`、空白符压缩），且检查通过不替代成稿时的原文上下文复核。

   - **防误报**：结合私有存档字段与上下文判定（例如等级缩写须带数字或处于私有字段上下文中才拦截，允许 NLP 笔记中的正常缩写）。
   - **三条实现与验收要求**：
     1. 白名单精确到具体匹配值（明确的公开 `noreply` 地址、占位路径、`/kaggle/working` 等平台路径），不按整文件豁免；

     3. 检查覆盖一次 `push` 中的各个 `commit`（逐个 commit 扫描，防止前序 commit 混入后被后续 commit 掩盖）。

## 3. 学习线协作框架（公共结构）

学习线的具体进度、待办和个人记录只在私有仓库 `Pan-Yan-0/personal_study_image` 及 Drive `10_交接/学习/` 的私有交接文档中维护，不在本公共文档列出。公共协作结构如下：

1. **同源试讲与主副分工**：GPT 聊天端与 Gemini 网页端均读取 Drive `10_交接/学习/` 下同一份教学规则与带预计算头的存档副本，按私有交接文档完成同题试讲后，由 Pan-Yan-0 定一位做**日常主讲**，另一位做**副手（论文查新检索 + 每周抽查 1 份新增笔记的数学与概念准确性）**。
2. **源头分离与异步同步**：学习收工时，在源头拆分为「公开笔记草稿」与「完整新存档」放进 Drive `10_交接/学习/`；Pan-Yan-0 方便时由 Antigravity 基建对话跑 `check_archive.py`（基础检查**已有**；新增 Unicode 下标拦截与预计算头剥离**已实现待验收**）后，分别推送到公开仓库与私有仓库，并刷新 Drive 副本顶部的预计算块。

## 4. 错误分级与四档修法

每被纠正一次，按顺序选修法，前一档做不到才选下一档并写明原因：
1. **改结构**：让错误没机会发生（例：状态只写一处；预计算结果由脚本写进文件头；`AGENTS.md` 拆开；公开与私有文档在源头分开）。
2. **自动检查**：活干完自动过一遍，犯了马上拦下（例：`check_archive.py`、`check_drafts.py`、`agents/check_repo_hygiene.py`）。
3. **写成规矩**：前两档做不到时才加；一条规矩被违反一次即升为“中度”，必须改成第 1 或第 2 档。
4. **Pan-Yan-0 抽查**：只留给硬规则与每周抽查清单，不作为修法。

| 级别 | 判定标准 | 处理步骤 |
|---|---|---|
| **轻** | 被已有自动检查拦下；或只影响单个未交接的文件 | 当场改，不记台账 |
| **中** | 越过了本该拦住它的环节，到了另一端或 Pan-Yan-0 手里；或同类错第二次出现；或别人已基于错误状态干活 | 止损 → 找本该拦住它的那一层 → 用第 1 或第 2 档修 → 注入错误做回归测试 → 记进 [纠错台账](纠错台账.md) |
| **重** | 进了给导师看的结论；隐私进了公开仓库；造成数据、算力或已发布帖子的不可逆损失 | 停掉这条线 → 回滚 → 改结构 → 回归测试 → 同步所有端 → 再恢复 |

历史纠错记录与扫描验收回执统一在 [纠错台账](纠错台账.md) 单点维护，不在本文重复抄写。
