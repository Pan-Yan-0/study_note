## 一、逐集要点整理

### 43. 神经元与大脑
- 人工神经元是数学函数：输入加权求和 → 过激活函数 → 输出。
- ❓ 与大脑的区别 → ✅ 见 Q&A-1。

### 44. 神经网络是什么（重点集）
- 与传统 ML 的核心区别：**特征不需要人工设计，网络在中间层自动学出特征**。
- 每一层把上一层所有输出作为输入（全连接 Dense）。
- ❓ 中间层到底学到了什么没人知道（可解释性问题）；层数/神经元数怎么定 → ✅ 见 Q&A-2、Q&A-3。

### 45. 图像案例
- 第一层神经元学边缘/局部纹理，中层学部件，高层学整体——感受野逐层扩大。
- 本集无疑问。（这就是「层次化特征」的直觉，和 Kaggle 作业里「词袋丢失层次」形成对照。）

### 46. 神经元的计算（数值演示）
- 每个神经元：先算 z = w·x + b，再过激活函数（本课用 sigmoid）得到输出。
- 分类任务：最后输出是 0~1 的数，设阈值（如 0.5）判断是/否。
- ❓ 「传递函数」的正式名字 → ✅ 叫**激活函数（activation function）**，见 Q&A-4。

### 47. 抽象成通用公式
- a^[l] = σ(w^[l] · a^[l-1] + b^[l])——本层输出 = 激活函数(权重 × 上一层输出 + 偏置)。
- ❓ sigmoid 到底是什么 → ✅ 见 Q&A-5（重点解答）。

### 48. 前向传播引出反向传播
- 前向传播：输入从第一层一路算到输出层，得到预测。
- ❓ 什么是反向传播、什么时候用哪个 → ✅ 见 Q&A-6（重点解答）。

### 49. TensorFlow 初体验（Dense）
- `Dense(units=3, activation='sigmoid')` = 一层 3 个神经元的全连接层。
- 手动串联：a1 = layer1(x); a2 = layer2(a1)... 每层返回一个可复用的「小函数」。
- 手写数字识别案例。输出仍可设阈值做二分类。

### 50. numpy 与 tensor
- `np.array([[1,2]])` 是 1×2 行向量（注意双层括号 = 二维）。
- TF 内部用 tensor，numpy 用 array，两者要经常互相转换（这是 TF 的麻烦之处）。
- ❓ PyTorch 是什么 → ✅ 见 Q&A-7。

### 51. Sequential 现代写法
- 把各层装进 `model = Sequential([dense1, dense2, dense3])`，前向传播自动串联。
- `model.compile(...)` 配置训练 → `model.fit(x, y)` 训练 → `model.predict(x)` 预测。
- 对比 sklearn 三动词：fit/predict 概念一脉相承！compile 是神经网络特有的（要指定损失函数和优化器）。

## 二、疑问解答（Q&A）

### Q&A-1（43 集）人工神经元怎么传递信号？和大脑有什么区别？
**传递方式**：人工神经元之间传的是**数字**——上一层每个神经元的输出是一个数，乘上连接权重 w 后全部加起来，再加偏置 b，过激活函数，结果传给下一层。所谓「传递信号」就是一次乘加运算 + 一次非线性变换。

**与大脑的区别**（知道结论即可）：
- 大脑神经元是**脉冲放电**（有/无的电化学尖峰），人工神经元是连续数值；
- 大脑有约 860 亿神经元、连接极其稀疏且可生长，人工网络结构是写死的；
- 大脑功耗约 20W，大模型训练要兆瓦级。
- 所以「神经网络」只是个**类比**，本质是「受大脑启发的数学函数」，别当真把它当大脑。

### Q&A-2（44 集）中间层到底学到了什么，没人知道吗？
对，这正是深度学习的**可解释性问题**（黑箱问题），你没有误解，这是学界公认的难题：
- 坏处：出了错不知道哪层错了；医疗/金融等场景不敢全信。
- 好处：正因为不人工指定特征，网络才能发现人类想不到的模式（这是它超过传统 ML 的原因）。
- 现状：有一个专门研究方向叫**可解释性 AI（XAI / Interpretability）**，2024 年 Anthropic 对 Claude 做的「特征可视化」就是前沿进展——你 45 集看到的人脸边缘/部件可视化，就是可解释性研究的最早期形态。

### Q&A-3（44 集）到底弄几层？每层几个神经元？
诚实答案：**没有理论公式，是经验 + 试出来的**（这叫「调结构/调超参」）。经验法则：
- 层数和神经元数 = 模型的「容量」。容量太小 → 学不好（欠拟合）；太大 → 背答案（过拟合，正好接上 IMDB 任务老师让你思考的问题）。
- 实操：从小开始（2-3 层、每层几十到几百），看验证集表现逐步加；现在更多时候直接用别人验证过的经典结构（如 BERT 的层数宽度是论文实验出来的）。
- 这就是 ML 被称为「炼丹」的原因——也是 71-87 集（偏差/方差/误差分析）要教你怎么科学地调。

### Q&A-4（46 集）「传递函数」的正式名字
叫**激活函数（activation function）**。46 集用的是 sigmoid，以后还会见 ReLU（现在最常用）、tanh、softmax。作用都是：给网络加入**非线性**（没有它，多少层堆起来都等价于一层线性变换，白搭）。

### Q&A-5（47 集）sigmoid 到底是什么 ⭐
定义：σ(z) = 1 / (1 + e^(-z))，图像是一条 S 形曲线：

```
输出 1.0 ┤                  ______
         │              ___/
 0.5     ┤          ___/
         │      ___/
 0.0     └______/┴──────────────
              z=0        z 越大越接近 1，越小越接近 0
```

- **干什么**：把任意实数 z（可以是 -∞ 到 +∞）压进 (0, 1) 区间。
- **为什么有用**：z = w·x + b 算出来是「打分」，可正可负没个范围；过 sigmoid 后变成 0~1 的数，**可以当「概率」用**——输出 0.87 就读作「87% 把握是好评」，配 0.5 阈值就能分类（46 集的阈值判断就是这么来的）。
- **和已学的联系**：它就是你第一部分学的**逻辑回归**用的那个函数！逻辑回归 = 单个神经元 + sigmoid。所以：一个神经元 = 一个逻辑回归；神经网络 = 一大堆逻辑回归层层嵌套。这层窗户纸捅破，47 集就不神秘了。
- 补充：现在隐藏层更多用 ReLU（f(z)=max(0,z)，计算快、缓解梯度消失），sigmoid 主要留在二分类的输出层。

### Q&A-6（48 集）前向传播 vs 反向传播，什么时候用哪个 ⭐
| | 前向传播 forward | 反向传播 backward |
|---|---|---|
| 干什么 | 输入 → 一层层算 → 得到预测 | 从输出的误差 → 一层层倒推 → 算出每个权重「该往哪调、调多少」（梯度） |
| 类比 | 考试答题 | 对答案 + 复盘错题 |
| 什么时候用 | **永远都用**：训练时要用，训练好之后每次预测也只用它 | **只在训练时用**，目的是配合梯度下降更新 w 和 b |

一次训练迭代 = 前向传播（算出预测和误差）→ 反向传播（算出梯度）→ 梯度下降（更新权重）。
训练结束后模型部署上线，**只剩前向传播**——这对你的 AI Infra 方向是关键事实：推理优化优化的就是纯前向传播的计算（这就是为什么推理可以少存梯度、少占显存）。

### Q&A-7（50 集）PyTorch 是什么？
- 和 TensorFlow **同级**的深度学习框架，Meta 出品。两者都是「tensor 计算 + 自动求梯度 + GPU 加速」的库。
- 现状：**学术界和业界当前主流是 PyTorch**（HF 的模型、vLLM/SGLang 这些推理引擎全是 PyTorch）。TF 主要存在于老项目和 Google 内部。课程教 TF 是因为它教学友好，你不用纠结，**先把概念学会，PyTorch 语法差异很小**。
- 对你路线的意义：你的 CUDA / AI Infra 路线将来打交道的就是 PyTorch——`imdb_*.py` 那包脚本就全是 PyTorch，跑它们的时候你自然就开始了。

## 三、概念卡（速查）

| 概念 | 一句话 |
|---|---|
| 神经元 | 一个逻辑回归单元：z = w·x+b，再过激活函数 |
| Dense 层 | 全连接层：这层每个神经元都接上一层所有输出 |
| 激活函数 | 加入非线性；sigmoid / ReLU / softmax |
| sigmoid | 把任意数压进 (0,1)，当概率用；σ(z)=1/(1+e^-z) |
| 前向传播 | 输入算到输出；训练+预测都用 |
| 反向传播 | 误差倒推梯度；只在训练时用 |
| Sequential | TF 里把层串成流水线的容器 |
| compile | 指定损失函数和优化器（NN 特有，sklearn 没有） |
| tensor | TF/PyTorch 里的数组，能上 GPU、能自动求导 |

## 四、和已有知识的连接

- 逻辑回归（第一部分 30+ 集）= 单神经元 + sigmoid → 神经网络是它的层层嵌套。
- sklearn 的 fit/predict ≈ TF 的 fit/predict，多一个 compile（因为 NN 要选损失和优化器）。
- Kaggle 作业的随机森林没有反向传播；IMDB 脚本包里的 CNN/LSTM 全靠反向传播训练——下次跑 imdb_cnn.py 时你就会看到 loss 逐 epoch 下降，那就是 48 集引出的事情在真实发生。
