## 一、原始笔记整理

### 60 · 训练细节
完整走了一遍神经网络全流程：识别 0/1 手写数字。现在的库（TensorFlow / PyTorch）十分成熟，不会从头造轮子，但**理解底层原理仍然十分重要**。

### 61–62 · 激活函数的选择
- 三种主力激活函数：**ReLU、线性（linear）、sigmoid**。
- 输出层二分类 → sigmoid；隐藏层一般 → ReLU。
- 隐藏层少用 sigmoid：有额外计算量（指数运算），且两端梯度趋近 0（后续「梯度消失」与此有关）。

### 63 · 为什么必须有激活函数
全部用线性激活函数 → 多层网络**数学上退化成线性回归**（线性函数的复合仍是线性函数）。隐藏层全线性 + 输出层 sigmoid → 退化成**逻辑回归**。

### 64–66 · Softmax 多分类
- 从 0~9 手写数字识别（10 类）引出 softmax。
- Softmax 是逻辑回归的推广：**维度 = 2 时等价于逻辑回归**。
- a_j = e^{z_j} / Σ_k e^{z_k}；损失 = −log(a_y)。
- 代码结构不变：Dense → Sequential → compile → fit → predict。

### 67 · Softmax 的数值稳定性改进
- 问题：分母 Σe^{z_k} 可能极大，浮点精度损失。
- 改进：输出层改**线性激活**（直接输出 z），compile 加 `from_logits=True`，predict 后手动套 softmax。

### 68 · 多标签分类（选修）
- 多分类：一个输入选一个类别（softmax）。
- 多标签：一个输入可同时属多个类别（输出层 sigmoid，各输出独立二分类）。

### 69 · Adam 优化器
自适应学习率：每个参数各自的有效步长，训练中自动调节。详解见答疑 Q4。

### 70 · 卷积层（CNN 引入）
- Dense：每个神经元接收上一层**所有**输入；卷积层：只看**局部小区域**，参数滑动复用。
- 例子：心电图 → 二分类（sigmoid 输出）。

## 二、答疑区

### Q1（ep65）：softmax 为什么用 e？零基础详解
输出层 10 个神经元各算出任意实数 z₁…z₁₀，要变成概率需满足：每个 ≥ 0、总和 = 1。
1. **为什么用 e^z**：e^x 对任何实数输入恒输出正数，把「任意实数」清洗成「正数」。
2. **为什么除以 Σe^{z_k}**：归一化，每个正数除以总和 → 结果在 (0,1) 且加起来 = 1。
3. **为什么偏偏是 e**：
   - 单调且指数级放大差距，最大项概率更尖锐；
   - e^x 导数是它自己，反向传播求梯度极方便（工程上的真正原因）；
   - 与 sigmoid 同源 → softmax 维度=2 时等价于逻辑回归。

损失：正确类别 y 的损失 = −log(a_y)，预测越自信且正确损失越小。这就是**交叉熵**。

### Q2（ep67）：为什么输出层改线性激活？from_logits 是什么？
线性激活就是「啥都不干」，a = z 原样输出。你的猜测正确。

| | 改进前 | 改进后 |
|---|---|---|
| 输出层激活 | softmax | linear（输出 z） |
| compile 损失 | `SparseCategoricalCrossentropy()` | `...(from_logits=True)` |
| predict 结果 | 已是概率 | logits，需手动 `tf.nn.softmax()` |

`from_logits=True`：告诉损失函数「传进来的是 logits」，在内部用 log 域技巧一步算完：`log(e^{z_j}/Σe^{z_k}) = z_j − log(Σe^{z_k})`，除法变减法，从根上避免精度损失。数学结果相同，计算顺序更聪明（类似 CUDA 的 kernel 融合思想）。

### Q3（ep67）：TensorFlow 全流程六步
```
1. 定义层   layer1 = Dense(units=25, activation='relu')   # 说明书
2. 组装     model = Sequential([layer1, layer2, layer3])  # 串成网络
3. 配置     model.compile(loss=..., optimizer=...)        # 怎么学（不传数据！）
4. 训练     model.fit(X, y, epochs=100)                   # ★ 唯一学习的一步，x,y 在这里传
5. 预测     model.predict(x_new)                          # 前向传播一次
6. 收尾     tf.nn.softmax(...)                            # from_logits 模式下转概率
```
fit 内部每轮做：前向传播 → 算损失 → 反向传播 → 更新参数。PyTorch 无 compile，手写四步 `forward → loss → backward → step`，概念一一对应。

### Q4（ep69）：Adam 详解
普通梯度下降所有参数共用一个学习率 α，但参数「脾气」不同。Adam（Adaptive Moment estimation）两个机制：
1. **一阶动量**：历史梯度的移动平均 m，像滚下山的球有惯性——方向一致加速，震荡抵消。
2. **二阶动量**：历史梯度平方的移动平均 v。梯度大的参数步长 m/√v 自动调小（防震荡），梯度小的相对调大（防太慢）。
有效步长 = 全局学习率 × 动量方向 ÷ 历史梯度大小，每步自动重算。默认 lr=0.001 通常就能用，这是它成为默认选择的原因。

### Q5（ep70）：卷积层在干什么？CNN 用在哪？
「旋转图片增加输入」是误记——那叫数据增强，另一回事。卷积的目的是：
- Dense 层每个神经元连所有输入，224×224 图片第一层就要 1.5 亿参数，算不动也没必要；
- 图像识别靠**局部模式**（边缘、角、纹理），一个神经元只看 3×3 小窗口即可；
- 同一组参数在整图上**滑动复用**（权值共享）→ 参数暴减 + 位置不变性（猫在左在右都能识别）。

CNN 用在一切有局部结构的数据：图像、信号（心电图 = 1 维卷积）、**文本**（IMDB 项目的 `Conv1d`：「not good」这种局部词组就是文本里的「边缘」）。
