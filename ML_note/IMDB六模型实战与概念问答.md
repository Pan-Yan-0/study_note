3. ⚠️ **第一节与第九节自相矛盾**：第一节说 AttLSTM"一跃成为亚军"，第九节又说"0.003 差距可能是噪声"。后者是对的：**0.89996 vs 0.89660 只差 0.0034，在单次运行的方差范围内，LB 排名的小数点后第三位不要当真。**

## 三、三元语法（n-gram）

### 我的问题

三元语法的频率，我发现一个很有意思的结论，什么是三元语法？

### 回答摘要

**n-gram** 就是把句子切成连续长度为 n 的片段。以 "this movie was great" 为例：

| 名字 | 长度 n | 切出来的片段 |
|---|---|---|
| unigram（一元） | 1 | this / movie / was / great |
| bigram（二元） | 2 | this movie / movie was / was great |
| **trigram（三元）** | **3** | **this movie was / movie was great** |

三元语法每次取连续三个词。n 越大上下文越完整，但 n 太大片段会变得极其罕见（稀疏性问题）。词表 10000 词时，trigram 最多 1 万亿种，而 IMDB 只有 2.5 万条评论，绝大多数 trigram 一次不出现，需要平滑技术。

**与 CNN 的隐藏对应**：CNN 的 kernel_size=3 本质上就是在扫描 trigram。CNN=局部 n-gram 视角；RNN=序列记忆视角；Transformer=全局关联视角。

> 【校验】✅ 数学核对：10000³ = 10¹² = 一万亿，正确。📌 "CNN 的 kernel_size=3 ≈ trigram"这个对应非常精彩且正确，唯一差别是：传统 trigram 是离散计数，CNN 是在稠密向量上做可学习的加权——可以理解成"软 trigram"，权重从数据学出来而不是人工数出来。这个洞察和你教程 M1 的"卷积核=特征探测器"讲的是同一件事。

## 四、NLP 与语言学

### 我的问题

我怎么感觉后面的nlp都是考虑语言学的东西？

### 回答摘要

NLP 处理的对象始终是语言，语言学从未离开，变化的是从"手工规则"变成了"模型自己学出来的东西"。

**深度学习前**（2010 年前）：NLP 必须懂语言学，流程是 原始文本→分词→词性标注→句法分析→提取人工特征→SVM 分类器，每个箭头都是语言学任务。

**深度学习把语言学"内化"了**：

| 你做的事 | 对应的语言学概念 | 谁提供的 |
|---|---|---|
| kernel_size=3 的卷积 | 三元语法、局部搭配 | 你设的超参数 |
| LSTM 遗忘门遇到 "but" 清空情感 | 话语转折、修辞关系 | 模型自己学的 |
| 双向 LSTM | 上下文依赖 | 模型自己学的 |
| 注意力权重 | 句法依存关系 | 模型自己学的 |
| GloVe 词向量 | 语义相似性 | 从语料统计出来的 |

前面两个是手动塞进去的，后面三个是模型自己长出来的。**语言学没有消失，它从代码里搬进了权重里。**

Tenney 等人（2019）发现 BERT 浅层做词性标注、中层做句法分析、深层做语义和指代消解，跟传统 NLP 流水线顺序一模一样。

**不同任务对语言学依赖程度不同**：

* 几乎不需要：IMDB 情感分类（词袋就能到 0.88）
* 非常需要：机器翻译、语法纠错、信息抽取、中文（分词歧义）

建议补**句法依存**——看懂注意力权重可视化就不再是一团乱麻。

> 【校验】✅ Tenney et al. 2019（"BERT Rediscovers the Classical NLP Pipeline"）引用准确。📌 "语言学从代码搬进权重"这个总结很好，但记住第九节千问自己引的 Jain & Wallace 警告：探测/可视化能看到相关性，不等于模型真的"按这个机制工作"。这两节连起来读才是完整图景。

## 五、齐普夫定律、BERT、可解释性、CNN/LSTM 理解

### 我的问题

齐普夫定律的指数是什么东西？我观察到bert一直被提及，这个是nlp主流的一个解决方法吗？还有我看到你的第二点里面说了这个内部到底学了什么，这个是可解释层面的东西吗？对此我觉得我应该是初步的理解了一下文本的预处理吧，你知道这个，也就是讲所有我们的数据文本的单词全部转换成id也就是正所谓的map表word to id，这个是十分重要的，因为转换成数字这种相对于文本来说更好处理的数据，但是在此之后，我认识了词频法来进行判断情感分析，那么再者之后我初步知道存在类似说有词袋之后到这种word2Vec词向量的形式，可以通过对于单一词汇与另一词汇的语义相近程度，但是再之后的话，其实我并不是特别知道其由来，你说CNN我知道，但是这个是否已经是模型选择方面的东西，并不是特征工程方面的东西呢，cnn的话是依靠获取了相邻词汇结合起来也就是语序，加上词义，两者进行判断吧？LSTM是更上一层还有一个是LSTM的改进版少了一个门，对于LSTM依靠遗忘门、记忆门、还有一个不知道什么门、输出这，通过这几种门相互配合，对于语序的理解还有对于CNN无法获取到大量也就是我们现在是设计的是临近三个词，LSTM依靠多门协作可以让具有情感词义的词可以相互结合起来进行判断，但是我感觉就是单向的话可能最终的输出会多是依靠最后的情感也就是可能会出现例如but把之前的给转折掉了，我觉得LSTM的方式更像是一种获取全部具有情感词义的，进行按顺序来进行思考学习，为什么（假设是监督学习）是good or bad。我上面的解释让我感觉我对神经网络还是不太适应，里面的黑箱操作让我无法解释其过程，这真是有一些不太好的感觉。

### 回答摘要

**齐普夫定律**：把词按频率从高到低排名，频率和排名成幂律关系 f(r) ∝ r^(-s)。s 就是指数，自然语言中 s 约等于 1（0.9~1.1 之间）。取对数后 log-log 坐标图上是直线，斜率 = -s。s>1 表示词汇更集中，s<1 表示更分散。这就是为什么要做停用词过滤和只保留高频词。

**BERT 是主流吗？** 是，但分场景：

* 文本分类等结构化任务：BERT 类小模型仍是工业界主力
* 需要生成/对话：大语言模型
* 数据很少/算力紧/要求可解释：简单模型（逻辑回归+TF-IDF）仍然合理

BERT 比 LSTM 强的核心原因：双向+注意力，且预训练可用海量无标注数据。LSTM 信息一步步传会衰减，BERT 任意两个词距离都是 1。

**"它内部学了什么"是可解释性吗？** 是，分三种：

* 探测（probing）：拿中间层表示训练简单分类器看能否完成语言学任务
* 归因（attribution）：看输入哪部分对输出贡献最大
* 结构简化：把大模型换成可解释的小模型

但要注意：探针能学到某性质不等于模型真的"用"了这个性质（Hewitt & Liang 2019）。

**知识链路**：词袋 → 词频/TF-IDF → word2vec/GloVe（静态表示） → ELMo（动态表示） → Transformer/BERT → 大语言模型。关键一跃是**静态表示→动态表示**（词义消歧能力）。

**CNN 是特征工程还是模型选择？** 深度学习把这两件事合并了。词向量=新的特征表示形式；CNN/LSTM/Transformer=特征提取器+分类器的端到端联合学习。选架构就是在选"用什么方式提取特征"。

**LSTM 理解修正**：

* 三个门是：遗忘门、输入门、输出门（不是四个）
* 单向 LSTM 最后输出不是"只看最后"，而是传递中信息被稀释
* "but 转折"不是覆盖而是遗忘门在 but 附近降低保留比例，是渐变的加权

**关于黑箱不适感**：

* 很多"黑箱现象"其实是 bug（你的 0.50004 就是代码错误）
* 有些可解释：看错例、消融实验、固定种子跑多次
* 部分确实不可解释：组合泛化等结构性局限

建议追求"理解输入输出的稳定关系+知道它在哪类情况会失败"，而非"理解每个神经元"。

> 【校验】✅ 全部核对通过（s≈1 的适用范围见总评第 5 条）。📌 你原始问题里有一段非常精彩的自述推理——"单向 LSTM 可能最终输出多依靠最后的情感、but 把之前的转折掉"，这个直觉在文献里有正式名字（recency bias / 梯度衰减导致的远端信息稀释），也正是双向 LSTM 和注意力存在的理由。你提到的"改进版少了一个门"是 GRU（三门→两门），正确。📌 "CNN 是特征工程还是模型选择"一问，千问的回答是深度学习的标准答案：**端到端学习 = 特征工程自动化**。这正好接上吴恩达课程里"深度学习 vs 传统 ML 需要人工特征工程"的对比（ep1–5 左右）。📌 对"黑箱不适感"的建议值得划线：目标是"知道它在哪类情况会失败"，这是工程师视角，比"理解每个神经元"可达且有用。

## 六、RNN 详细讲解

### 我的问题

attlstm，这个看着还真不错，那你现在能十分详细的进行解释说明一下这个RNN吗？或者先进行说明一下RNN是什么，其运作机制，其神经元，其数学公式等。

### 回答摘要

**RNN 要解决的问题**：输入是固定长度的模型（逻辑回归/MLP/CNN 图像）无法处理变长序列。RNN 两个核心思想：①逐个读入（sequential）②参数共享（parameter sharing）。

**核心机制**：隐藏状态 h = 记忆。每步输出由"当前输入"和"过去全部历史"共同决定。

**朴素 RNN 公式**：

* h_t = tanh(W_hh × h_{t-1} + W_xh × x_t + b_h)
* y_t = W_hy × h_t + b_y

**展开图**：把自循环按时间轴摊平，变成一个很深的、每层权重完全相同的前馈网络。前向传播=从左往右（forward through time），反向传播=从右往左（BPTT）。

**神经元层面**：RNN 隐藏神经元比 MLP 多了一项"来自上一步自己的输入"。每个时间步接收两个信号：外部信号（x_t）和内部信号（h_{t-1}）。从第一步开始信息就在做有损压缩——这就是黑箱源头。

**Vanilla RNN 致命缺陷：梯度消失**。tanh 导数恒小于 1，一连串矩阵连乘导致梯度指数级衰减趋近于 0。长距离依赖学不到。

**LSTM 解决方案**：把隐藏状态拆成两条路——细胞状态 C_t（长期记忆，高速公路）和隐藏状态 h_t（短期输出）。C_t 更新中有直接加法：C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t。加法求导是常数 1，梯度可以畅通传回。三个门分别是遗忘门、输入门、输出门。

**GRU**：LSTM 瘦身版，三个门合并为两个（更新门+重置门），C_t 和 h_t 合并为一个状态，参数量少约 25%。GRU 在 IMDB 上拿第一（0.89996）不是因为更强，而是参数少、和数据量更匹配。

**AttLSTM 的注意力**：打分发生在 LSTM 全部跑完之后，在循环外面。流程：Embedding → BiLSTM 产出 states → Attention 打分 → softmax → 加权 → sum 聚合 → Linear 分类。Attention 解决的不是"理解能力"而是"信息利用效率"。

> 【校验】⚠️ "tanh 导数恒小于 1"的精度问题见总评第 1 条。🔍 "GRU 拿第一是因为参数少"是假设非结论，见总评第 2 条。✅ 其余公式与机制描述全部正确："加法求导是常数 1"对应 ∂(u+v)/∂u = 1，是梯度高速公路的数学核心；"参数共享"是 RNN 与 CNN 共同的思想源头，吴恩达在序列模型里强调过同一点。📌 "Attention 解决的不是理解能力而是信息利用效率"——这句话非常准确，建议划线记住：LSTM 已经"看过"所有词，注意力只是解决"最后用哪部分"的问题。

## 七、LSTM 门机制与注意力详解

### 我的问题

我观察你后面所说的似乎有一定的理解，比如遗忘门的这个输出，在我看来更像是计算权重，需要将之前的进行遗忘多少呢？这样的一个权重，之后输入门开始计算，本次的word的词义是否需要进行进行在整体的记忆之中或者说其带来的情感在我们之中是否需要加多少，并且来一轮tanh（这种东西还是激活函数吗），之后值得一提的是这个ot是个什么东西也就是输出门的输出，很奇怪的是我们的神经网络层的输出会进行传递给下一层，对于lstm我看到的是我觉得是只有ht进行传递到下一层但是很奇怪的是对于每一个神经元都会有一个输出，那么是ht进行传递吗？还是说什么？我看到其用处是在隐藏状态输出中作为权重进行更新我们的ht，还有一个比较重要的，是否我需要完全进行理解其数学原理，毕竟我还是一个研究生。值得一提的是我看懂了这个朴素RNN的缺点也就是一开始我就看出来这个相乘必定是会存在遗忘也就是在数学层面上会出现多个小数相乘导致的数值变得特别小，这个lstm的思路是换成了+的形式来进行避免了这种情况，根本方法就是+的形式避免这个多个小数相乘的问题，你可能会有疑问我问什么会很经常询问神经元干什么干什么因为在吴恩达教授的讲解中会很经常的具体到神经元，所以说我会比较希望去看到每一个神经元到底干了什么比如画一个图数据的传递是什么的，具体到每一个神经元的或者说是每一个神经网络隐藏层的，对于attlstm，这个所谓的每一步打分是哪里开始就进行打分呢？每一个隐藏层就开始进行打分了吗，还是说如何呢？还有，这个注意力的定义是什么意思？我刚刚看了一个有关注意力的人的方面的解释吧，对于注意力比较的复杂，无意识的输入，意识开始进行判断，比如有一个黑白打印的，其中有一个红色的东西，那么对于人来说注意力会被红色的东西吸引，这个是一个粗略的注意力的解释，那么我们在机器学习应该是说深度学习中，如何利用这个注意力呢？

### 回答摘要

**门就是"权重计算器"**：门是向量（长度=hidden_size），逐维度决定保留比例。门不是人设定的，是算出来的。本质是数据依赖的、逐维度的、可学习的软开关。

**tanh 当然是激活函数**：σ 负责"决定比例"(0~1)，tanh 负责"提供有符号的内容"(-1~1)。两者分工明确。

**o_t 的作用**：C_t 是内部工作笔记（无边界），h_t 是对外说的话（有界）。o_t 是从笔记到发言的阀门，决定暴露多少内部记忆。

**什么被传出去？** 只有 h_t 传出去，C_t 永远不离开这一层。多层 LSTM 时，第 1 层 t 时刻输出 h_t(1) 立刻变成第 2 层 t 时刻的输入 x_t(2)，时间是同步的。

**CEC（恒定误差传送带）**：LSTM 根本方法是加法避免连乘小数。这不是纯加法而是"加权求和"，f_t 接近 1 但不永远等于 1。这个模式后来成为深度学习通用设计范式（ResNet 残差连接、GRU、Transformer 残差+LayerNorm 都是同一思想）。

**研究生需要理解到什么程度**：

* L1 必须：前向公式能默写；每个张量形状能说出来；知道梯度为什么消失、加法怎么解决
* L2 建议：能手推单步梯度；知道 BPTT；知道为什么用 tanh 不用 ReLU
* L3 看方向：完整 BPTT 推导、谱半径分析
* L4 不必：背诵每一篇变体细节

**AttLSTM 打分从哪里开始？** 从 LSTM 全部跑完之后才开始。打分发生在第 3 步，输入是"最后那一层 LSTM 产出的全部隐藏状态"，不是每一层都打分。

**注意力从人类直觉到机器实现**：

* 人类注意力是"硬的"（只看一个），机器注意力是"软的"（全部参与，权重不同）
* 必须软是因为只有软操作才可微，才能用反向传播训练
* 通用模板：score(q,k) → softmax → 加权求和
* 警告：注意力权重不等于模型的解释（Jain & Wallace 2019），别把它当证据

> 【校验】✅ 本节全部核对通过，质量极高。四个点值得特别划线：①"门=数据依赖的、逐维度的、可学习的软开关"——比"门就是权重"更精确，因为权重来自当前输入和上一个 h，每个时间步都在变；②"C_t 是内部笔记、h_t 是对外发言"的比喻与真实机制吻合；③CEC→ResNet→Transformer 残差的范式迁移——这是深度学习里最重要的一条暗线，你将来读 vLLM/推理优化论文时还会不断遇到它；④"必须软才能可微"是注意力设计的根本约束。📌 你问"是否要完全理解数学原理"——千问给的 L1~L4 分级很合理，对你（AI Infra 方向）建议做到 L2：能手推单步梯度就够，谱半径那类属于理论研究。📌 你注意到"吴恩达经常具体到神经元"——这是好的学习习惯，保留它。

## 八、激活函数、反向传播、AttLSTM 数据流

### 我的问题

我有一些基础概念的问题，这个激活函数，到底是用在什么地方，是具体到神经元还是说是什么，是神经元输出的东西需要搞一个激活函数，还是啥？对于我的学习程度，你的意思是我应该对于这种经典算法的各种也就是神经元或者说是LSTM的各种门的哪些公式都应该可以手动进行写出来，并且是可以理解各种算法的梯度变化（值得一提的是这个应该是反向传播的东西，其实我还没有进行深度的学习反向传播这个到底是如何进行运转的神经元的运作方式或者说各个隐藏层到底是干嘛的），对于你说的attlstm也就是在期间我们加多一列来进行打分也就是对于我们的ht我们加多一个维度来进行记录分数，之后在第四部中我们开始对于这一个维度开始进行加权？我这次希望具体到各个数据。

### 回答摘要

**激活函数用在神经元输出端**：输入 → 加权求和（+偏置） → 激活函数 → 输出。它是神经元计算的一部分，不是层之间的额外零件。没有激活函数，深层网络退化为单层线性变换。

PyTorch 的 Linear/Conv/Embedding 本身不带激活函数，需手动添加。

**softmax 是耦合型操作**：分母包含所有神经元，改变任意一个位置的分数，所有位置权重都会变化。这是理解注意力的关键细节。

**修正：AttLSTM 不是给 h_t 加一列记录分数**。分数是独立的张量（seq,batch,1)，用完即弃。h_t 维度从头到尾不变。

用具体数字走了一遍完整流程：

* states 形状（4,1,4) → 打分得到 score(4,1,1) → softmax 得权重（4,1,1) → 广播乘法加权 → sum 聚合为（1,4) → Linear 分类

原始代码真实尺寸表：

* 输入（64,512) → Embedding(64,512,300) → permute(512,64,300) → BiLSTM(512,64,256) → Attention 打分（512,64,1) → softmax(512,64,1) → 加权（512,64,256) → sum(64,256) → Linear(64,2)

**反向传播直觉**：前向回答"参数确定时损失是多少"，反向回答"参数微调一点损失变动多少"。依赖链式法则，局部且模块化。

**LSTM 加法救梯度**：∂C_t/∂C_{t-1} = f_t，当 f_t 约等于 1 时导数约等于 1，连乘 100 次还是 1。对比朴素 RNN 的连乘小于 1 的数。

**公式手写建议**：只针对"不理解公式就无法 debug"的模块手写。LSTM 门控公式值得（能发现维度拼错），Transformer 缩放点积完整推导暂不值得。

> 【校验】✅ 尺寸表核对：BiLSTM 输出 256 = 128×2 双向拼接，正确；attention 在 seq 维（512）上 softmax 聚合，正确。📌 千问纠正了你"给 h_t 加一列记分数"的想象——这个纠正很重要，正确图景是：**分数是旁路计算出来的新张量**，h_t 本身不被修改，只在最后一步被分数加权。📌 "softmax 是耦合型操作"这个细节说得极好，它解释了为什么 padding 会污染权重（见第九节），也解释了 Transformer 里为什么 mask 必须在 softmax 之前做。📌 反向传播你没深学这件事不用焦虑——黄海广笔记第 9 章就是反向传播推导，配合吴恩达 ep42–51（神经网络直觉）一起看正好。

## 九、需要注意的问题

### 我的问题

似乎本轮来说我几乎已经理解了各个问题，你觉得哪些是我还需要进行注意的？

### 回答摘要

**三个"你以为懂了"的技术点**：

1. **Padding 污染注意力权重**：pad 位置参与 softmax 竞争，会分走权重稀释真实词汇。修复：加 mask（softmax 前把 pad 分数压到 -inf）。
2. **dim=0 写死脆弱**：前提张量形状为（seq,batch,1)，哪天改 batch_first 就会悄悄出错且不报错。
3. **双向拼接后首尾意义变了**：att_out[0] 前半来自正向第 0 步，后半来自反向第 0 步（看得到整句话），正反向视野不对称。

**实验方法问题（比理论更重要）**：

1. **固定 epoch 比较不公平**：不同模型最佳停止点不同。应记录每个 epoch 验证集分数取 best，加早停。
2. **0.003 差距可能是噪声**：单次运行方差不在这个量级。应多跑几个种子看均值±标准差。
3. **没有 baseline**：建议跑 TfidfVectorizer+LogisticRegression，判断任务信号集中在哪里。
4. **建实验记录表**：记录每次运行的模型/超参/种子/train acc/val acc/test 分。
5. **别过度拟合 public leaderboard**：LB 只基于部分测试集，反复提交调参本质是用测试集做验证。

**反向传播练习**：手推一个两层 MLP（带 ReLU）的前向+反向，用 PyTorch autograd 核对数值。做完这一次就够了。

**学习方式提醒**：容易在一个概念上反复打磨直到"完全通透"才往下走。深度学习的现实是：很多概念只有亲手写代码、看到报错、跑出反常结果后才能真正理解。原则：理解到能动手的程度就停手，让实验反过来教你。

**下一步清单（按性价比）**：

1. 加 padding mask（可能直接提 0.5~1 个点）
2. 改 best-epoch 取值+画学习曲线
3. 跑 TF-IDF baseline
4. 开词向量微调+Dropout 配早停
5. 同种子多次运行看方差
6. 做一次注意力可视化

> 【校验】✅ 这一节是全文含金量最高的部分，所有技术点全部正确。三个"你以为懂了"中第 1 条（padding 污染）在你当前教程的 M4 Attention 代码里**真实存在**——教程 softmax 没带 mask，这正是下一步要改的。第 5 条"别过拟合 LB"对应吴恩达课程里"dev set 过拟合"的警告（ep71–87 区间）。📌 "理解到能动手的程度就停手，让实验反过来教你"——这条已经写进我们的教学 skill 2.0 的精神里了：区分"能解释"与"能独立做"，用产出倒逼理解。

## 十、BERT 详解

### 我的问题

十分不错，现在将我跟你的所有对话进行弄出一个文件，主要是我发给你的不能太压缩，你的回答可以进行一些压缩。

（注：此轮实际问题是关于 BERT 的，见上文第 10 轮对话；问题原文未录入）

### 回答摘要

BERT 本质上是一个"预训练好的通用语言理解底座"。核心逻辑：先在海量无标注文本上学会"读懂语言"，再通过微调迁移到具体任务。

**BERT 与 LSTM 对比**：

| 对比项 | LSTM | BERT(Transform) |
|---|---|---|
| 处理方式 | 串行 | 并行 |
| 长距离依赖 | 靠隐藏状态传递会衰减 | 自注意力直接计算 |
| 上下文 | 单向或双向拼接 | 真正的双向 |
| 训练效率 | 慢 | 快 |
| 参数量 | 小（百万级） | 大（BERT-Base 1.1 亿） |

**架构**：只用了 Transformer 的 Encoder 部分，堆叠 12 层（BERT-Base）或 24 层（BERT-Large）。每层有两个子模块：多头自注意力+前馈网络，外包裹残差连接+LayerNorm。

**输入表示**：三种 Embedding 逐元素相加：Token Embedding + Segment Embedding + Position Embedding。特殊标记：[CLS]（句首，输出取此位置向量做分类）和 [SEP]（分隔符）。

**预训练任务**：

1. **MLM（掩码语言模型）**：随机遮盖 15% 的词预测被遮盖的词。80% 替换为 [MASK]，10% 替换为随机词（防作弊），10% 保持不变（强迫真正靠上下文）。
2. **NSP（下一句预测）**：判断两句是否连贯。后续 RoBERTa 等发现帮助有限已弃用。

**预训练数据**：BooksCorpus（8 亿词）+英文维基百科（25 亿词），训练 100 万步。

**微调范式**：

* 传统方式：每个任务单独设计架构+从头训练
* BERT 方式：统一架构，只改输出层。分类任务取 [CLS] 向量接 Linear；序列标注用每个 token 输出；问答用起止位置预测。
* 微调策略：特征提取（冻结 BERT 只训输出层）或全量微调（BERT 也用更小学习率）

**BERT 家族演进**：

* 中文优化：BERT-wwm、ERNIE、MacBERT
* 轻量化：DistilBERT、ALBERT
* 架构改进：RoBERTa（去掉 NSP、动态掩码）
* 领域专用：BioBERT、FinBERT
* 预训练目标改进：ELECTRA

> 【校验】✅ 数字全部核对通过：BERT-Base 1.1 亿参数、12/24 层、MLM 15% 与 80/10/10 规则、BooksCorpus 8 亿词+维基 25 亿词。📌 注意一个与你自己项目的连接：你在 IMDB 教程 Part A 里"冻结 GloVe"就是本节"特征提取（冻结，只训输出层）"的同款策略；Part D 的 DistilBERT 微调就是"全量微调"。预训练→微调这个范式，本质是你已经学过的迁移学习（ep80–85）在 NLP 里的形态。

## 附：知识总览

### 完整知识链路

```
文本
↓ word→id（vocab map，离散符号数字化）
索引
↓ Embedding / GloVe（静态语义表示）
x_t ∈ R^300
↓ 逐时间步递推
BiLSTM
f_t = σ(...) 遗忘比例
i_t = σ(...) 写入比例
o_t = σ(...) 暴露比例
C_t = f⊙C_{t-1} + i⊙C̃_t 加法保梯度
h_t = o⊙tanh(C_t) 只有 h_t 外传
↓ states = 全部 h_t 的集合 (512, 64, 256)
Attention：打分 → softmax → 加权 → sum
↓ (64, 256)
Linear → softmax
↓
正/负概率
```

### 组件归属总表

| 组件 | 属于哪一层 | 它做了什么 |
|---|---|---|
| word→id（vocab map） | 数据表示 | 离散符号→整数索引 |
| Embedding / GloVe | 特征表示 | 索引→稠密向量，语义相近的词距离近 |
| Conv1d(kernel=3) | 特征提取器 | 局部 trigram 扫描，并行、无记忆 |
| RNN / LSTM / GRU | 特征提取器 | 序列建模，靠隐藏状态传递历史信息 |
| Attention | 信息聚合 | 把整条序列按重要性压缩成一个向量 |
| Linear + softmax | 分类头 | 向量→概率 |

### 模型演进路线

```
词袋 (bag of words)
↓ 问题：丢失语序、维度爆炸、语义无关
词频 / TF-IDF
↓ 同上，只是加了权重
word2vec / GloVe ← 静态表示，一词一向量
↓ 突破：语义相近的词向量也相近
↓ 致命缺陷：一个词只有一个向量（静态）
ELMo (2018)
↓ 突破：词的表示由整句话决定（动态、上下文相关）
Transformer / BERT (2018)
↓ 突破：双向+注意力，且预训练可用海量无标注数据
大语言模型 (2020-)
↓ 突破：生成式、指令跟随、涌现能力
```

> 【校验】📌 这张演进路线和 `evolution.html`（NLP 模型演进深度史）是同一叙事的文字版，可以对照看。注意它省略了 CNN 一支（CNN 是并行旁支不是主线的一环），别误解成"CNN 被淘汰了"——你的实验里 CNN 0.88880 仍在第一梯队。
