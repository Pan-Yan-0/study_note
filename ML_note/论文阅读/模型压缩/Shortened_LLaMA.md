# Shortened LLaMA 阅读笔记

- 论文：Shortened LLaMA: Depth Pruning for Large Language Models with Comparison of Retraining Methods（Kim 等，arXiv 2402.02834）
- 发表：ICLR 2024 workshop（ME-FoMo）
- 读法：定向阅读。不是完整三遍，只为回答[研究想法记录](研究想法记录.md)想法 1 的问题：这篇固定了哪些条件，又在什么条件下比较了深度剪枝和宽度剪枝。

---

## 1. 它做了什么

| 项目 | 内容 |
|---|---|
| 剪什么 | 整个 Transformer 块（深度剪枝），一次性删除 |
| 怎么选块 | 两种指标：PPL（删掉这一块后困惑度涨多少）和 Taylor+（一阶泰勒重要性，见 [AdaPruner.md](AdaPruner.md)） |
| 校准数据 | BookCorpus，10 条样本 |
| 模型 | LLaMA-7B、Vicuna-7B / 13B（v1.3） |
| 宽度剪枝的对照 | LLM-Pruner、FLAP、Wanda-sp |
| 恢复方式 | Table 2：所有方法都用 LoRA（Alpaca 5 万条，一张 A100，不到一天）。Table 3：剪 20–80% 的高剪枝率，只有作者的深度剪枝模型做继续预训练（CPT，SlimPajama，8 张 H100，不到两周） |
| 主要结论 | 同样用 LoRA 恢复、参数量相近时，深度剪枝的零样本准确率能打平甚至超过宽度剪枝，而且在小 batch 下推理更快；剪枝率高时，CPT 比 LoRA 恢复得好得多 |

---

## 2. 和想法 1 的关系：固定了什么，比较了什么

**控制变量是在每一张表里做的，不是整篇论文统一控制。**

| 表 | 固定 | 改变 | 能回答的问题 |
|---|---|---|---|
| Table 2 | 模型、剪枝率（7B 约 20% / 35%，13B 约 21% / 37%，按参数量对齐）、恢复方式（都用 LoRA、同一份数据）、评测 | 剪枝方法（深度 PPL / Taylor+ 对宽度三种） | LoRA 恢复下，深度剪枝和宽度剪枝哪个好 |
| Table 3 | 作者自己的深度剪枝模型 | 恢复方式（LoRA 对 CPT）和剪枝率（20–80%） | 深度剪枝在高剪枝率下用哪种恢复更好 |

**这篇没有回答的**：
- 宽度剪枝模型没有做 CPT，所以"用了更强的恢复后，宽度剪枝会不会反超"这个问题仍然开放。Minitron 在 50% 剪枝率、蒸馏恢复下看到宽度更准，正好落在这个空档里。
- LoRA 和 CPT 的数据、可训练参数、算力都不同，Table 3 只能说明"这一套 CPT 配方恢复得更好"，不能说明是哪一个因素起的作用。
- 评测主要是零样本多选题和 PPL，没有生成和推理任务。

## 3. 读的时候冒出的想法（Pan-Yan-0）

- **"一个方法对应解决一个问题"**：PPL 指标和 Taylor+ 指标在不同的设置下各有胜负，说明每个指标针对的问题不同，没有通吃的指标。
- **剪枝率的甜点和多个指标投票**：是否存在一个剪枝率，在它以内深度剪枝最划算；能否让几个重要性指标像专家一样投票，共同决定删哪些层。已记入[研究想法记录](研究想法记录.md)想法 2，还没有查新。

## 4. 易混点

| 容易说错的 | 正确说法 |
|---|---|
| 这篇证明了深度剪枝比宽度剪枝好 | 只在"同样用 LoRA 恢复、剪枝率约 20–37%"的条件下打平或更好；高剪枝率下宽度剪枝没有用 CPT 恢复，比较不完整 |
| CPT 比 LoRA 好，所以恢复方式决定一切 | CPT 和 LoRA 之间数据量、训练参数、算力都不同，是一整套配方的差别 |
| 零样本就是不训练 | 零样本（zero-shot）指评测时提示里不给示例；模型本身可以经过剪枝和恢复训练。给几个示例叫少样本（few-shot） |
| 控制变量要求整篇论文所有实验条件都相同 | 每一组比较（一张表）内部只改一个变量就行，不同的表可以回答不同的问题 |
