## 1. 八项笔记

| # | 项目 | 内容 |
|---|---|---|
| 1 | 要解决什么问题 | 大模型太大，部署成本高。作者发现各层之间存在明显冗余：有些层对输入几乎没有改变，删掉影响很小。 |
| 2 | 以前的方法哪里不够 | 量化（quantization）：降低参数的数值精度，但要有特定的硬件支持，效果才能发挥出来。剪枝（pruning）：很多方法复杂，有的还需要梯度信息（如 LLM-Pruner），影响实用性。 |
| 3 | 具体改了什么 | 提出 BI（Block Influence）指标：BI = 1 − 某层输入和输出的平均余弦相似度。按 BI 从小到大排序，删掉 BI 最小的 n 层，n 事先决定（不是阈值；用阈值的是 LaCo）。只做前向，不需要梯度，也不需要标签。 |
| 4 | 最能支持主张的实验 | Table 2：支撑"比其他剪枝方法好"。Figure 3：支撑"BI 能反映层的重要性"。Figure 5：支撑"BI 比其他指标好"。 |
| 5 | 最想问导师的问题 | 删层以后生成式任务几乎崩掉。组里以前做层剪枝时遇到过吗？这个问题还值得做吗，还是已经被恢复训练这类方法基本解决了？ |
| 6 | 剪什么 | 整层，即深度剪枝（depth pruning），是粒度最粗的结构化剪枝。 |
| 7 | 怎么恢复 | 主结果（Table 2）不做恢复。§4.6 / Table 6 试了后训练：用轻量 MLP 替换被删的层，再训练。Llama2-7B 平均分 41.22 → 43.16（+1.94），XSum 0.67 → 4.89，WSC、BoolQ、Race-M 反而下降。删除比例从 27.1% 变成 24.0%，补进去的 MLP 本身有参数。数据和训练量见附录 F（待确认）。 |
| 8 | 怎么评估 | 14 个任务的分数和保留率 Per.。没有显存数据；速度只有 Table 4 一处：在 GPTQ 量化模型上删 27% 的层，吞吐只提高到 1.19 倍。 |

## 2. 方法流程（§3.2）

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1 | 准备校准集（calibration set） | 无标签文本，比如 PG19 |
| 2 | 模型在校准集上做前向推理 | 只做前向，参数不变 |
| 3 | 收集每层的隐藏状态 | 第 i 层的输入 X_i、输出 X_{i+1} |
| 4 | 算出每层的 BI | 对所有样本、所有 token 取平均；可以边跑边累加，不必存下全部隐藏状态 |
| 5 | 按 BI 升序排列，删掉最小的 n 层 | n 用来在速度和性能之间权衡 |

**公式 (1)**：BI_i = 1 − 𝔼_{X,t} [ X_{i,t}ᵀ X_{i+1,t} / (‖X_{i,t}‖₂ ‖X_{i+1,t}‖₂) ]

- X_{i,t}：第 i 层、第 t 个 token 的隐藏状态，Llama2-7B 里是一个 4096 维的向量。它是激活，不是参数。
- ‖·‖₂：L2 范数，即向量的长度 = √(各元素平方之和)。

## 3. 读表时算过的数（Llama2-7B）

| 项目 | 计算 | 结果 |
|---|---|---|
| 平均保留率 Per. | 41.24 ÷ 47.78 × 100 | 86.31% |
| MMLU（多选题，multiple-choice） | 43.96 ÷ 45.39 × 100 | 96.85% |
| XSum（生成式任务，generative） | 0.67 ÷ 19.40 × 100 | 3.45% |

结论：平均保留率会掩盖任务之间的差别。删层对多选题伤得很少，对生成式任务几乎是毁灭性的。另外，Ave. 把 14 个任务看成一样重要，XSum 的分数范围本来就小，它崩掉在平均值里只占很小一部分。

## 4. 比较是否公平（Table 2）

| 事实 | 回答了什么 | 没回答什么 |
|---|---|---|
| 所有方法都不做恢复训练（LLM-Pruner 原有的后训练被去掉了） | 不做恢复时，哪种剪枝方法更好 | 恢复训练以后谁更好 |
| 三个基线的数字抄自 LaCo 论文，ShortGPT 的数字是作者自己跑的 | — | 两套评测流程（提示格式、工具版本、硬件精度）是否一致。同一个配方在 T4 fp16 和 A10 bf16 上跑，结果就能差约 1 个百分点 |
| 删除比例不完全相同（27.0% / 26.4% / 27.1%） | 大致相同规模下的比较 | — |

**跨论文的线索**：Minitron 用蒸馏恢复后发现，宽度剪枝的版本更准，深度剪枝的版本更快。加上恢复训练后，"深度比宽度好"在精度上可能反过来。读 Minitron 时要核对。

## 6. 易混点

| 容易说错的 | 正确说法 |
|---|---|
| ShortGPT 按阈值删层 | 删 BI 最小的 n 层，n 事先定；用阈值的是 LaCo |
| 量化的不足是"降低精度" | 降低精度是量化在做的事；作者说的不足是要有特定硬件支持 |
| "精度" | 参数的数值精度（precision，比如 16 位、4 位），不是答对的准确率（accuracy） |
| 长度之积：把 3 平方得到 9 | 长度 = √(平方和)，‖(3, 0)‖ = 3 |
| 无标签就没有学习信号 | 无标签指不需要人工标注；语言模型的下一个 token 本身就是答案 |
| 恢复用的 LoRA 加在被删的层里 | 被删的层已经没有了；LoRA 挂在剩下各层的权重矩阵上，训练完可以合并回原权重 |
