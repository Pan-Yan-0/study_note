## 1. 第一遍的六个问题

| # | 问题 | 内容 |
|---|---|---|
| 1 | 要解决什么问题 | 从零训练一系列大小不同的模型太贵。已有工作（原版 Minitron）用"结构化剪枝 + 知识蒸馏"压缩，但前提是蒸馏时能用到原始预训练数据；现在的前沿模型大多用私有数据训练，这个前提不成立。 |
| 2 | 方法 | 两个互相独立的改进：(1) 教师校正（teacher correction）：先用新的蒸馏数据集把未剪枝的教师微调约 100B token，再用它去蒸馏；(2) 深度剪枝的选层指标：每次删一段连续的层，看下游任务 Winogrande 掉多少。 |
| 3 | 主要证据 | Table 1（基座模型）、Table 2（指令微调后）。消融实验在 Figure 4–9，第二遍再看。 |
| 4 | 和谁比 | Gemma2、Mistral 7B、Llama 3.1 8B、Phi-2、Qwen2-1.5B、原版 Minitron 4B 等。MN-Minitron-8B 在同等规模里大多最好，只用了 380B token（Llama 3.1 8B 用了 15T）。 |
| 5 | 局限 | 没有专门的局限一节。第 4 页提到：教师校正后，有些下游任务反而变差（作者认为是数据集造成的）；未来可以用更少的 token、LoRA 或只调归一化层来做校正。 |
| 6 | 和前两篇对照 | 深度和宽度都做，并分开比较；用蒸馏恢复。见第 3 节。 |

## 2. 流程（Figure 1、Figure 2）

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1 | 教师校正 | 未剪枝的教师在新数据集（Nemotron-4）上用交叉熵微调约 100B token。原因：教师是在原始数据上训练的，到了新数据上，它给的概率不够准（作者认为是子词分布不同） |
| 2 | 估计重要性 | 宽度：在 1024 条校准样本上做前向，按注意力、MLP、LayerNorm 的激活值，给每个头、神经元、嵌入通道打分。深度：删掉一段连续的层，看 Winogrande 的分数 |
| 3 | 剪枝 | 按重要性排序，直接裁剪权重矩阵 |
| 4 | 蒸馏恢复 | 学生 = 剪枝后的模型。只对 logits 算前向 KL 散度，不用交叉熵；4B 用 94B token，8B 用 380B token |

一句话：先让老师熟悉新教材，再让老师去教学生。Figure 5 显示，教师校正也可以和蒸馏同时进行。

## 3. 三篇对照

| | ShortGPT | AdaPruner | Minitron |
|---|---|---|---|
| 剪什么 | 整层（深度） | 层内耦合结构（宽度） | 深度、宽度都做，分开比较 |
| 怎么选 | BI，只做前向 | 泰勒重要性，要梯度 | 宽度：激活值，只做前向；深度：删连续的层，看 Winogrande |
| 怎么恢复 | 主结果不恢复；附加实验用 MLP 替换再训练 | LoRA 微调 | 蒸馏 |
| 算力 | — | 一张 RTX 3090 | 32 个 DGX H100 节点 |

**和 ShortGPT 的直接冲突**

- Minitron 明确不用 BI（第 3 页："We do not consider the Block Importance (BI) metric [8]"，[8] 就是 ShortGPT）。
- 按逐层重要性删 16 层，Winogrande 只有 0.5；删掉连续的第 16–31 层，有 0.595（第 6 页）。

**"深度还是宽度"的结论反过来了**

- ShortGPT（不恢复）：深度剪枝比宽度剪枝好。
- Minitron（蒸馏恢复，Figure 7、Table 1）：宽度剪枝更准（MMLU 60.5 对 58.7；GSM8K 41.2 对 16.8），深度剪枝更快（吞吐 2.7 倍对 1.8 倍）。
- 两篇的模型和数据也不同，不能直接说是恢复方式造成的。要在同一个模型上只改恢复方式，才能确定。

## 4. 易混点

| 容易说错的 | 正确说法 |
|---|---|
| 教师校正是为了拿回原始预训练数据 | 原始数据拿不到，就换成能拿到的数据集；教师校正是让教师适应这个新数据集 |
| 教师校正和"基于下游任务的指标"是一回事 | 两个独立的改进：一个改教师，一个改深度剪枝怎么选层 |
| ShortGPT 是 Minitron 的子集 | 两篇都做深度剪枝，但选层方法相反：一个按 BI 挑层，一个删连续的一段 |
| 剪枝后的模型连没剪枝的都比不过 | MN-Minitron-8B 是从 12B 压缩来的。和从零训练的 8B 比，回答的是"从大模型压缩是否比从零训练更省、更好" |

论文自身的小矛盾：宽度剪枝的吞吐提升，第 2、6 页写 1.8 倍，第 7 页 Insights 写 1.7 倍。
