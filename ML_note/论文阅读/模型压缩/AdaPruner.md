## 1. 第一遍的六个问题

| # | 问题 | 内容 |
|---|---|---|
| 1 | 要解决什么问题 | 现有结构化剪枝随机选取校准数据，并且固定只用一种重要性指标（比如 LLM-Pruner 的 E1 只用一阶、E2 只用二阶），剪完后性能下降。Figure 1 显示：换一种校准数据分布、换一种指标，各任务的结果会变好或变差。 |
| 2 | 方法 | 构建"结构化剪枝解空间"：校准数据子空间（从 BookCorpus 里选样本）× 重要性指标子空间（粗粒度的权重向量指标和细粒度的权重元素指标，按系数 α₁、α₂ 加权，公式 5）。用贝叶斯优化（BO-TPE）在这个空间里搜索，目标是剪完、还没微调时，在 WikiText2 和 PTB 上的平均困惑度最低（公式 6）。搜到以后剪枝，再用 LoRA 在 Alpaca 上微调。 |
| 3 | 主要证据 | Table 1：LLaMA-7B 剪 20%，不微调和微调两种设置下，大部分指标最好。另有 Table 2（消融）、Table 3（Vicuna-7B）、Table 4（剪 50%）、Figure 4（贝叶斯优化约 150 次收敛，随机搜索约 300 次）。 |
| 4 | 和谁比 | Magnitude、Vector、LLM-Pruner-E1 / E2、MoreauPruner，微调设置下还有 LoRAShear，剪 50% 时还有 Wanda。AdaPruner 是建在 LLM-Pruner 上的（耦合结构的依赖分析、泰勒重要性都来自它），所以和它比，回答的是"加上搜索后多带来了多少"。例外：OBQA 两种设置都不是最好；微调后的 WinoGrande 是 LoRAShear 更高（65.83 对 65.40）。 |
| 5 | 局限 | 作者没写局限，只写了未来工作：更广的解空间设计、更多类型的模型。要自己找：搜索的目标是"剪完未微调时的困惑度"，最终报告的却是微调后的常识任务分数，两者一致吗？（第三遍讨论） |
| 6 | 和 ShortGPT 对照 | 剪什么：层内的耦合结构，属于宽度剪枝；ShortGPT 删整层，属于深度剪枝。恢复：LoRA 微调（Alpaca）；ShortGPT 主结果不恢复。AdaPruner 同时报告了不微调和微调两种结果。 |

## 2. 两篇论文的重要性指标

| | ShortGPT：BI | AdaPruner：泰勒重要性 |
|---|---|---|
| 衡量什么 | 这一层把输入改变了多少 | 把参数置为 0 以后，损失变化多少 |
| 怎么算 | 1 − 输入和输出的平均余弦相似度 | 一阶近似：\|梯度 × 参数值\|；二阶还要加 Hessian（用 Fisher 信息近似） |
| 要不要梯度 | 不要，只做前向 | 要：先在无标签文本上算预测下一个 token 的损失（公式 1），再求梯度 |
| 粒度 | 整层 | 权重向量（粗）和权重元素（细），再汇总到耦合结构组 |

小例子：某个权重 θ = 0.5，损失对它的梯度是 0.2，一阶重要性是 |0.2 × 0.5| = 0.1。

ShortGPT 在引言里批评"有的剪枝方法需要梯度信息"，指的就是这一类方法。

### 一阶泰勒重要性

想法：把一个参数置为 0，损失大约变化多少？泰勒展开给出近似：

- 损失的变化 ≈ 梯度 × 参数的变化量：ΔL ≈ g × Δθ
- 置为 0 时 Δθ = −θ，所以 ΔL ≈ −gθ；重要性 I = |gθ|

| 权重 | θ | g | ΔL ≈ g × (−θ) | I = \|gθ\| |
|---|---|---|---|---|
| A | 0.8 | 0.05 | −0.04 | 0.04 |
| B | 0.1 | 0.6 | −0.06 | 0.06 |
| C | −0.5 | 0.2 | +0.10 | 0.10 |

- 按泰勒重要性先剪 A；只看权重大小 |θ| 会先剪 B。两种做法选的不同。
- 为什么要看梯度：梯度的**大小**是损失对这个参数的敏感度。重要性 = 敏感度 × 改动有多大。A 权重大但不敏感，B 权重小但很敏感，只看权重会错删 B。
- ΔL 带符号，I 取绝对值，是两样东西。
- 梯度来自校准集上预测下一个 token 的损失，只算梯度、不更新参数；比 BI 多一次反向传播。
- 它只是局部近似：把很大的权重直接置 0 是一大步，近似可能不准，所以公式 (2) 还加了二阶项。

**组合多个指标、或者学出一个判断器？** AdaPruner 本身就是把粗、细粒度指标按系数组合再搜索；也可以给每个结构配可学习的开关（mask）来训练，例如 Sheared LLaMA。代价是更贵：ShortGPT 的卖点是一次前向就够，AdaPruner 是多花搜索代价换来更好的选择，并不是更快。

## 4. 易混点

| 容易说错的 | 正确说法 |
|---|---|
| 贝叶斯优化是数学上推出最优解 | 公式 (6) 把目标写成优化问题，但求解靠反复"选组合 → 剪枝 → 测困惑度"的黑盒搜索，类似超参数搜索 |
| "单一指标"说不通，明明有好几种 | 以前的方法各自固定只用一种；AdaPruner 把几种按系数组合起来再搜索 |
| WikiText2、PTB 是分类任务 | 它们测困惑度，越低越好（表头的 ↓） |
| 规模定律是数学证明 | 规模定律是用实验数据拟合出的经验规律 |
