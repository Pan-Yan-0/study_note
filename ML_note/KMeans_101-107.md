### 102 · 什么是聚类
无监督学习的第一种：数据**没有标签**，算法自己把相似的样本归成一堆（簇）。例子：市场细分、新闻聚合、基因分组。概念简单。

### 103 · K-means 的直观理解
用具体数据演示簇心（centroid）如何一步步移动到各堆数据的中心。

### 104 · K-means 算法流程（⚠️ 你的描述顺序反了，见 Q1）

### 105 · 优化目标与必然收敛
- K-means 有一个明确的代价函数（失真函数 distortion）：
  ```
  J = (1/m) · Σᵢ || xⁱ − μ_{cⁱ} ||²
  ```
  即「每个样本到它所属簇心的距离的平方」的平均。
- 你写的 `1/m(sum(||xi-c||^2)` 方向正确（细节见 Q2）。
- **必然收敛的原因**：算法的每一步（分配样本、移动簇心）都只会让 J 减小或不变，J 又有下界（≥0），所以必然停在某处——但停的不一定是全局最优。

### 106 · 随机初始化与局部最优
- 初始化：随机选 K 个**训练样本**作为初始簇心。
- 可能陷入局部最优（簇分得不合理）。对策：**多跑几次**（如 50–1000 次）不同随机初始化，选 J 最小的那次。不能打包票拿到全局最优，但概率大很多。

### 107 · 如何选择 K
- 没有银弹。**肘部法则（elbow method）**：画 K vs J 曲线，找「拐点」——但现实中曲线常常很平滑、没有明显拐点，所以教授说这方法经常不好用。
- 实务建议：按**下游用途**选 K（比如做 T 恤尺码，S/M/L 就 K=3），让业务目标决定。

## 二、答疑区（两处修正）

### Q1（ep104）：⚠️ 算法流程的正确顺序
你写的「先分好簇的坐标，之后让样本被分到一些类」把两步合并了。标准流程是一个**交替循环**：

```
1. 随机初始化 K 个簇心（位置随意）
2. 重复以下两步直到不再变化：
   a. 分配步：每个样本 → 划给【离它最近】的簇心      （样本动）
   b. 移动步：每个簇心 → 移到它名下所有样本的均值处   （簇心动）
```

记法：**「样本选簇心 → 簇心取均值」两步交替**。分配步固定簇心优化归属，移动步固定归属优化簇心——每一步都在降 J，这就是 105 集收敛性的来源。

### Q2（ep105）：⚠️ 公式细节
你的写法基本对，规范形式是 `J = (1/m) Σ ||xⁱ − μ_{cⁱ}||²`，注意三点：
- 是 xⁱ 到**它所属簇心** μ_{cⁱ} 的距离，不是到任意 c；
- 距离要**平方**（平方和大，离群样本惩罚重）；
- 外面除以 m 取平均。
