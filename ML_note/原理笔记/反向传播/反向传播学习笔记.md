# 反向传播学习笔记

训练的完整链条：

```text
数据 → 模型 → 分数 z → softmax 得 p → 和正确答案 q 算交叉熵损失 L → 求梯度 → 更新参数
└────────────── 前向计算 ──────────────┘   └──────── 反向传播 + 梯度下降 ────────┘
```

- 前向计算只算到损失 L，参数不变。
- 反向传播从 L 往回求每个参数的梯度。
- 梯度下降按梯度改参数。

本笔记从最后一层开始往回推，用的网络是：

```text
x → a = W₁ x → h = ReLU(a) → z = W₂ h → softmax → p → L
```

分类模型的分数 z 也叫 logits，例如 BERT 分类头的 2 个输出、大模型 LM 头的 151,936 个输出。

**乘法的写法**：本笔记把 x、h 都看成列向量，W x 表示 W 的**每一行**和 x 做点积，第 i 行对应第 i 个输出。另一种写法 x W（例如 BERT 笔记里的 H × W_q）是 x 和 W 的**每一列**做点积。两种都对，但一道题里只能用一种。

## 1. 最后一层：损失对分数的梯度

### 1.1 两条规则

| 规则 | 式子 |
|---|---|
| softmax 加交叉熵时，损失对分数的梯度 | ∂L/∂z = p − q |
| 梯度下降 | 新值 = 旧值 − 学习率 × 梯度 |

∂L/∂z = p − q 是两段链式法则合起来的结果：∂L/∂p × ∂p/∂z。

### 1.2 例子

软标签 q = (0.8, 0.2)，模型输出 p = (0.6, 0.4)：

| | positive | negative |
|---|---:|---:|
| 梯度 p − q | 0.6 − 0.8 = −0.2 | 0.4 − 0.2 = +0.2 |
| 梯度下降后分数的变化 | 上升 | 下降 |

- 梯度为负，减去它分数就上升；梯度为正，分数就下降。
- 推动的幅度和"差多少"成正比；p = q 时梯度为 0，不再变化。这和交叉熵在 p = q 时取最小值一致（见[解码器大模型与路线 C 学习笔记](../LLM/解码器大模型与路线C学习笔记.md) 5.4）。
- 硬标签时 q 只有正确类别是 1：正确类别的梯度是 p − 1（负，分数上升），其他类别是 p（正，分数下降）。
- p、q 各自加起来都是 1，所以 p − q 的各项加起来一定是 0。

### 1.3 和学过的内容的联系

- **SFT 只在答案位置算损失**：只有答案位置的分数有 p − q 这个梯度，其他位置不产生梯度。
- **蒸馏**：把 q 换成老师的软标签，p − q 把学生的分布推向老师的分布。
- **LoRA**：梯度照样一路往回传，但只用来更新 A、B，原来的权重冻结不动。

## 2. 第二层的参数 W₂

z 是激活，不能直接改；能改的是参数 W₂。第 k 个分数 z_k = w_k · h，w_k 是 W₂ 的第 k 行。

```text
∂L/∂w_k = ∂L/∂z_k × ∂z_k/∂w_k = (p_k − q_k) × h
```

例：h = [2, 1]，∂L/∂z_pos = −0.269，学习率 0.1

| | 值 |
|---|---|
| ∂L/∂w_pos | −0.269 × [2, 1] = [−0.538, −0.269] |
| 更新 | w_pos − 0.1 × [−0.538, −0.269] = w_pos + [0.0538, 0.0269]，两个分量都变大 |
| z_pos 的变化 | 0.0538 × 2 + 0.0269 × 1 ≈ +0.135，上升，正确答案的分数被推高 |

- 减去一个负的梯度，等于加。
- w_pos 只管 z_pos，所以只用 z_pos 的梯度；z_neg 的梯度属于 w_neg。

## 3. 梯度传到 h

h 的每个分量对每个分数都有贡献，所以要把各个分数传回来的梯度加起来：

```text
∂L/∂h = Σ_k (∂L/∂z_k) × w_k
```

例：p − q = (−0.269, +0.269)，w_pos = [1, 0.5]，w_neg = [−1, 0.5]

∂L/∂h = −0.269 × [1, 0.5] + 0.269 × [−1, 0.5] = [−0.538, 0]

- h₁ 对 positive 的权重是正的，对 negative 是负的，h₁ 变大对正确答案有利，所以梯度为负。
- h₂ 对两个分数的权重相同，改它不会改变两者的差距，所以梯度为 0。
- h 是激活，这个梯度**不用来改 h**，而是继续往前传，去算前一层参数 W₁ 的梯度。W₂ 的梯度在第 2 节已经直接求出来了，用不到 ∂L/∂h。

## 4. 穿过 ReLU 到 W₁

```text
∂L/∂a = ∂L/∂h × ReLU′(a)       ReLU′ 在 a > 0 时为 1，a ≤ 0 时为 0
∂L/∂W₁ 的第 i 行 = ∂L/∂a_i × x  与第 2 节 (p − q) × h 是同一个规律
```

例：∂L/∂h = [−0.538, 0.4]，a = [1.5, −0.5]，x = [2, 1]

| | 值 |
|---|---|
| ∂L/∂a | [−0.538 × 1, 0.4 × 0] = [−0.538, 0] |
| ∂L/∂W₁ 第 1 行 | −0.538 × [2, 1] = [−1.076, −0.538] |
| ∂L/∂W₁ 第 2 行 | 0 × [2, 1] = [0, 0] |

第 2 行梯度为 0，更新量 = 学习率 × 0 = 0，所以这一步不变。原因是 a₂ < 0，ReLU 把这个神经元关了，它对这条样本的损失没有贡献。参数变不变，看的是它自己的梯度，不是"有没有算出损失"。

## 5. 反向传播和梯度下降的分工

```text
∂L/∂W₂ = ∂L/∂p × ∂p/∂z × ∂z/∂W₂
         └─── p − q ───┘   └─ h ─┘
∂L/∂W₁ = ∂L/∂p × ∂p/∂z × ∂z/∂h × ∂h/∂a × ∂a/∂W₁
         └─── p − q ───┘   └ W₂ ┘  └ReLU′┘  └ x ┘
```

- 两条链的前面几段相同。从后往前算，每一段都能直接用上后面已经算好的结果，每段只算一次，所以叫"反向"传播。
- 只有参数（W₁、W₂）会被更新；x、a、h、z、p 是激活，下一次前向时用新参数重新算出来。

| 步骤 | 做什么 | PyTorch |
|---|---|---|
| 反向传播 | 用链式法则从 L 往回推，算出每个参数的梯度 | `loss.backward()`，结果存在每个参数的 `.grad` 里 |
| 梯度下降（优化器） | 参数 ← 参数 − 学习率 × 梯度 | `optimizer.step()` |

## 7. 易混点

- **梯度对谁求，就更新谁；最终只更新参数。** p、z、h 是激活，下一次前向用新参数重新算。
- **减去负的梯度等于加**：梯度为负的参数往上走。
- **∂L/∂h 不用来改 h**，而是传给前一层的 W₁；W₂ 的梯度直接是 (p − q) × h。
- **反向传播与梯度下降**：前者算梯度（`loss.backward()`），后者改参数（`optimizer.step()`）。
- **W x 与 x W**：按行点积还是按列点积，一道题里只用一种。
- **梯度为 0 的参数不变**：ReLU 关着的神经元，对应的那一行这一步不更新。
- **自查的关系**：损失、熵、KL 都 ≥ 0；交叉熵 ≥ 熵；p − q 各项之和为 0；算出的 z 过 softmax 要和给定的 p 对得上；训练应把正确答案的分数往上推。

- 第 1 节的数字用下面的代码核对，数值梯度和 p − q 一致：

```python
import math

def softmax(z):
    e = [math.exp(x) for x in z]
    return [x / sum(e) for x in e]

def loss(z):  # 正确答案是第 0 类
    return -math.log(softmax(z)[0])

z, eps = [1.0, 0.0], 1e-6
p = softmax(z)                                  # [0.7311, 0.2689]
grad = [p[0] - 1, p[1] - 0]                     # [-0.2689, 0.2689]
num = [(loss([1 + eps, 0]) - loss([1 - eps, 0])) / (2 * eps),
       (loss([1, eps]) - loss([1, -eps])) / (2 * eps)]   # 与 grad 相同
z_new = [z[i] - 0.1 * grad[i] for i in range(2)]         # [1.0269, -0.0269]
print(softmax(z_new)[0], loss(z), loss(z_new))           # 0.7415 0.3133 0.2991
```

- 两层网络考试用 autograd 核对：

```python
import torch
x = torch.tensor([1., 2.])
W1 = torch.tensor([[1., 0.5], [-1., 0.25]], requires_grad=True)
W2 = torch.tensor([[1., 0.5], [-1., 0.5]], requires_grad=True)
q = torch.tensor([0., 1.])

z = W2 @ torch.relu(W1 @ x)
L = -(q * torch.log_softmax(z, dim=0)).sum()
L.backward()                      # 反向传播：算出 W1.grad、W2.grad
print(L.item(), W1.grad, W2.grad)

with torch.no_grad():             # 梯度下降：参数 ← 参数 − 学习率 × 梯度
    W1 -= 0.1 * W1.grad
    W2 -= 0.1 * W2.grad
print(-(q * torch.log_softmax(W2 @ torch.relu(W1 @ x), dim=0)).sum().item())
```
