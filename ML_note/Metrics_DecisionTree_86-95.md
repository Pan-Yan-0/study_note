## 一、原始笔记整理

### 86 · 倾斜数据集与精确率/召回率
- 问题：类别极度不平衡时（如 99% 是 y=0），模型「偷懒」全猜多数类也能拿到很高准确率——**准确率失效**。
- 解决：用 **混淆矩阵**（真实值 × 预测值的 2×2 表）算出两个新指标：
  - **Precision（精确率）**：预测为 1 的样本里，真的是 1 的比例——「我报的警有多少是真的」；
  - **Recall（召回率）**：真实为 1 的样本里，被抓出来的比例——「真的坏人我抓到了多少」。

### 87 · F1 指标与 P/R 权衡
- 权衡方式：调整阈值（高阈值→P 高 R 低；低阈值→P 低 R 高），按业务选（癌症筛查宁错杀：要高 R）。
- **F1 = P 和 R 的调和平均**，自动偏向较小的那个（纠正：公式见答疑 Q1）。

### 88–89 · 决策树的形状与学习流程
- 决策树 = 一串 if-else 嵌套成树；同一批特征可以组合出**很多棵不同的树**。
- 学习流程：每个节点选一个特征划分，让子集越来越「纯净」，递归直到纯净或到达停止条件。
- 88 集的疑问「怎么决定树的形状」= 89 集的疑问「节点选哪个特征」——**答案就是 91 集的信息增益**，你的问题意识方向完全正确。

### 90 · 纯度的度量：熵（entropy）
- 熵衡量一个子集有多「混」：全纯 → 熵 0；五五开 → 熵最大 1。（公式记忆略有偏差，见答疑 Q2）

### 91–92 · 信息增益（information gain）
- 单看划分后子集的熵不够，要问「**比划分前降了多少**」：
  - 信息增益 = 划分前的熵 − 划分后两个子集熵的加权平均（权重=子集大小占比）；
  - **每个节点选信息增益最大的特征**——这就是 88/89 集问题的答案；
  - 整个过程是递归：对每个子节点重复选特征、再划分。
- 教授说「实际用库」——对，sklearn 的 `DecisionTreeClassifier` 几行搞定，但理解增益原理才能调参。

### 93 · 独热编码（One-Hot）
- 多值离散特征（如颜色=红/绿/蓝）→ 拆成多个 0/1 特征，**每条样本只有一个为 1**。
- 树模型和线性模型都常用；你 Kaggle 作业的词袋本质上是「词维度版」的同类思想。

### 94 · 连续特征的处理
- 连续特征 → 试不同的切分点 x，变成「大于 x / 小于 x」的二分类，照样算熵和信息增益，选增益最大的切分点。

### 95 · 回归树（选修法）
- 用树预测**连续数值**：选特征时不算熵，改算**方差**——选让左右子集「加权方差」最小的划分；
- 预测值 = 叶子节点里所有样本 y 的平均值。

## 二、答疑区（含两处公式纠正）

### Q1（ep87）：⚠️ F1 公式记错了
你写的 `PR/2(P+R)` 不对，正确的是：

```
F1 = 2PR / (P + R)
```

记忆法：调和平均 = 「2 倍乘积 ÷ 和」。你的版本分子分母恰好写反了一半（把 2 放到了分母侧、除变乘）。验证一下「偏向较小者」的特性：P=1, R=0.1 → F1 = 2×0.1/1.1 ≈ 0.18，确实被 R 拖下来了。

### Q2（ep90）：⚠️ 熵公式的小笔误
你写的 `h(p0) = -p0·log(p0) - (1-p1)·log(1-p1)` 里第二项写串了（出现了 p1）。正确的是单变量形式：

```
H(p) = -p·log₂(p) - (1-p)·log₂(1-p)
```

p 是子集中正类的比例。你说「和逻辑回归的代价函数很像」——观察敏锐：它们都是**交叉熵**家族的形式 −p·log(q)，机器学习里反复出现。

### Q3（ep88/89 疑问的闭环）
「树的形状怎么定」→ 不是人为定的，是算法自动长的：每个节点算所有候选特征的信息增益，选最大的划分，递归下去。所以**树的形状 = 数据 + 信息增益规则的自然结果**。96–98 集会讲「一棵树容易过拟合 → 很多棵树投票」，那就是你 Kaggle 拿 0.846 的随机森林了。
