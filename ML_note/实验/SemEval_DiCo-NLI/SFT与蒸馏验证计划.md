## 结果与范围

现有英语 fold 0 三种子结果：Qwen CE / CE+dropout / R-Drop / SCL / MoCo 的对称化 WF1 分别为 85.25 / 86.13 / 84.79 / 85.33 / 85.57%；mDeBERTa CE / KD 为 78.55 / 78.87%。KD 三个种子均小幅提升，但尚无跨折证据。其他三个赛道已有 SFT 基线，尚未完成对应的蒸馏验证。

本次优先完成英语的五折验证：Qwen SFT 基线、对应老师的 mDeBERTa KD，以及学生 CE 对照。五折覆盖全部训练样本的折外预测，不等于四语言赛道、所有训练技巧和官方隐藏测试全部完成。现有 fold 0 已用于探索，因此新增折属于后续验证；最终五折汇总仍需注明这一选择过程。

## 控制变量与防止泄漏

1. 沿用现有家族分组五折，冻结fold映射。Qwen、教师导出、学生CE、KD逐项核对fit/val/holdout的ID及文本哈希；任一不一致即停止对应任务。内层划分沿用已有算法，不能为新方法重新抽取。
2. 每个老师只用本折fit训练，按本折val选择轮次，不接触本折holdout。fit内的反向输入只来自该fit；不得导入其他折老师的概率。老师给自己fit样本提供软标签是普通蒸馏，不是交叉拟合教师。
3. Qwen固定第六组CE配方、最多3轮、种子42/43/44。KD温度、权重、学生训练轮数沿用已核验第五组配置，实施时从源配置读取并在指纹中逐项记录，不做参数搜索。
4. 复用第五组学生CE作为对照前核对全部配置和软件环境。若无法匹配，补跑对应CE并单独估时，不能直接把差异全归因于KD。
5. 每个方法同时报告plain/sym的WF1、SoftCons、HardCons。官方dev只报告，不选超参数、轮次或方法。
6. 每种子拼接五折OOF后统一评分，不把五个WF1简单平均冒充OOF WF1；每种子英语OOF应有3042行且每个ID只出现一次。报告种子配对差、逐折差、种子离散程度，以及家族重抽样区间；不把15个任务当作15个独立数据集。

## 跑完后要回答的问题

- SFT在五折是否稳定领先学生CE？按相同数据划分作系统比较，明确模型、训练方式差异，不把差异都归因于参数规模。
- KD是否在多折、多种子上改善CE？老师正确/学生错误的样本有多少被纠正，老师错误是否被传递？同时统计原本正确却被KD改错的样本。
- 方向约束下降是否集中在某类关系？分别看plain、sym及反向输入，不能用构造后的SoftCons直接证明学到了方向关系。
- 各模型共同错误是否集中于语义边界、单词替换或标注歧义？按家族抽取代表错例共同审阅，不自动改金标。

先由结果定位问题，再围绕知识迁移、语义关系表示、选择性一致性约束等方向查原始论文。现阶段这些是研究问题，不能写成已证实的瓶颈机制。
