## 问题

- **票数几乎打平**：19 对 18，规则是算力筛选，过线不说明教师整体更对。RL / SL 是否有用要看 A1 的训练结果。
- **按格子看有方向性**（事后描述，不作依据）：教师把标签改成 O 时多数是对的（E → O 4 / 4、F → O 3 / 3、B → O 2 / 3），把 O 改成别的类时多数是错的（O → F / B / E：生成标签较对 9、教师较对 3）。只改向 O 的重标是一个候选设计，要另行事先登记，不在本轮做。
- **低置信的一致行审阅多不同意**（7 / 9 可判定）：教师概率低时，即使 argmax 和生成标签相同，这条生成行也常有问题。SL 会把这部分概率质量交给学生，LS 则不会。
- Claude 盲初标（`e2c5cdc7…`）只作描述：和 Codex 最终标签都给确定标签的 57 行里 37 行相同。
