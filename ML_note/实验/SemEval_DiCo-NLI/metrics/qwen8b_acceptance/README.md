# Qwen3-8B：A10 工程验收结果

## 结果

实验 A（见[计划](../../更大模型与数据扩充计划.md)第 2 节）正式运行前的工程验收，由 Pan-Yan-0 在阿里云 PAI-DSW 的 A10 上运行，全部通过。15 个正式任务没有启动，等 11 月的额度。

| 检查 | 结果 |
|---|---|
| 模型准备 | 4B、8B 都是已核验的 ModelScope 本地快照，没有回退到 HF 镜像 |
| 历史 4B 零样本 | dev 所需的 762 个输入，概率和 A10 上缓存的结果最大差 0，argmax 全部一致 |
| 新旧入口短程训练 | 同一份 4B adapter、确定性设置下 3 次真实更新：首批损失和概率差 0，三次更新后 504 个 LoRA 张量逐位相同 |
| 8B 提示词 | `enable_thinking=False` 时插入空的 think 块，"Answer:" 在最后；四个答案字母各是单个 token，损失落在最后一个真实 token |
| 8B 最长输入探测 | 批 8 × 2 放得下：最长提示 222 个 token，训练和推理峰值显存 17.0 GiB（A10 共 24 GiB）；1,448 个推理输入用时 98 秒 |
| 8B SMOKE | 第 2 轮模拟中断后从第 1 轮的检查点恢复，写坏的检查点被拒绝；每轮权重重载后内层验证概率差 0；ForwardCheck 两条路径都是 bf16 autocast、差 0 |
| 选定配置 | 批 8 × 累积 2（有效 16），bf16；正式运行估计每任务约 40 分钟，15 个任务约 10 小时、约 70 计算时（含 35% 余量，不含模型下载） |

SMOKE 和探测的分数只用来检查流程，训练量很小，不作为结果。

## 问题

- 这次运行的代码身份是 `ce340cba…`（v4），Claude 审过的是 v2；v2 之后的改动（验收回执等）还没经 Claude 复核，11 月正式运行前补上。
