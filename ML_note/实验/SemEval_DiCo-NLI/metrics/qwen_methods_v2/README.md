差值由未舍入的均值计算。三个种子对称化 WF1 的配对差（R-Drop 减 CE）：fold 0 为 −0.98/−1.22/+0.84 个百分点，dev 为 +1.63/+1.87/+0.58 个百分点。fold 0 种子间样本标准差由 0.26 增至 1.32 个百分点。dev 三个种子都提升，但留出折并不稳定，不能宣布 R-Drop 胜出。

三个指标、逐条预测及概率分别在 [CE](ce_results/) 和 [R-Drop](rdrop_results/) 目录。所有方法均报告原方向和对称化结果；R-Drop 不直接约束交换短语后的方向一致性。更完整的变量与家族配对重抽样比较见[实验登记表](../../实验登记表.md)。

### SCL 完整结果

SCL 三个种子均完成 3 轮、411 次更新，由内层验证选中第 3/3/2 轮。训练会话合计约 53.2 分钟，峰值显存 8.82 GiB。

| 分区/推理 | CE WF1 | SCL WF1 | 差值（百分点） |
|---|---:|---:|---:|
| fold 0 原方向 | 83.50% | 83.84% | +0.34 |
| fold 0 对称化 | 85.25% | 85.33% | +0.09 |
| dev 原方向 | 82.57% | 82.00% | −0.57 |
| dev 对称化 | 82.68% | 82.56% | −0.12 |

fold 0 对称化 WF1 的逐种子差为 +1.08/+1.17/−1.99 个百分点；种子间样本标准差为 1.65 个百分点，CE 为 0.26。平均分接近，但波动更大，不能说 SCL 已稳定改进。dev 的逐种子差为 −0.57/+0.13/+0.07 个百分点。

对称化后的 fold 0 SoftCons/HardCons 为 .9356/.8816（CE .9189/.8713）；dev 为 .9338/.8640（CE .9230/.8568）。原方向 fold 0 为 .8494/.8147（CE .8340/.8069），dev 为 .8363/.8063（CE .8351/.8014）。一致性均值有改善，但 WF1 没有同步提高；不能用一个指标代替其他指标。后续检查不同标签的损失与收益，以及三个种子的共同错例。

[完整 SCL 输出](scl_results/)包含三个种子及最终汇总；此前只有两个种子的包是阶段性输出，不作为正式均值。SCL 与 CE 的比较是整个 SCL 配方（投影头、混合损失）的比较，不把差异单独归因于某一个组件。
