# 第六组 Qwen：CE 与 R-Drop

## 结果

Pan-Yan-0 在阿里云 PAI-DSW A10 上运行，bf16，三个种子 42/43/44，英语 fold 0；每个种子训练 3 轮、411 次更新。CE 和 R-Drop 使用同一份 v2 源码、固定模型快照和依赖版本。R-Drop 由内层验证选中第 2/2/3 轮，CE 均选中第 3 轮。

| 分区/推理 | CE WF1 | R-Drop WF1 | 差值（百分点） |
|---|---:|---:|---:|
| fold 0 原方向 | 83.50% | 81.98% | −1.52 |
| fold 0 对称化 | 85.25% | 84.79% | −0.45 |
| dev 原方向 | 82.57% | 81.71% | −0.86 |
| dev 对称化 | 82.68% | 84.04% | +1.36 |

差值由未舍入的均值计算。三个种子对称化 WF1 的配对差（R-Drop 减 CE）：fold 0 为 −0.98/−1.22/+0.84 个百分点，dev 为 +1.63/+1.87/+0.58 个百分点。fold 0 种子间样本标准差由 0.26 增至 1.32 个百分点。dev 三个种子都提升，但留出折并不稳定，不能宣布 R-Drop 胜出。

三个指标、逐条预测及概率分别在 [CE](ce_results/) 和 [R-Drop](rdrop_results/) 目录。所有方法均报告原方向和对称化结果；R-Drop 不直接约束交换短语后的方向一致性。更完整的变量与家族配对重抽样比较见[实验登记表](../../实验登记表.md)。
