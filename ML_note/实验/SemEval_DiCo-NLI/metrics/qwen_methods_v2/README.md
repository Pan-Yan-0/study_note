# 第六组 Qwen 完整结果

## 结果

五种设置均已完成英语 fold 0、种子 42/43/44，每个种子训练 3 轮、411 次更新。CE+dropout 的首次下载超时已经补跑成功。各运行使用同一份 v2 训练源码、A10 bf16、固定模型快照和依赖版本。

| 方法 | fold 0 原方向 WF1 | fold 0 对称化 WF1 | dev 原方向 WF1 | dev 对称化 WF1 | fold 0 对称化种子标准差 |
|---|---:|---:|---:|---:|---:|
| ce | 83.50% | 85.25% | 82.57% | 82.68% | 0.26 个百分点 |
| ce_drop | 83.50% | 86.13% | 81.91% | 82.90% | 0.83 个百分点 |
| rdrop | 81.98% | 84.79% | 81.71% | 84.04% | 1.32 个百分点 |
| scl | 83.84% | 85.33% | 82.00% | 82.56% | 1.65 个百分点 |
| moco | 83.71% | 85.57% | 82.42% | 83.53% | 0.19 个百分点 |

差值按未舍入分数计算。

| 配对比较（对称化 WF1） | fold 0 平均差 | dev 平均差 |
|---|---:|---:|
| ce_drop − ce | +0.88 个百分点 | +0.22 个百分点 |
| rdrop − ce_drop | -1.33 个百分点 | +1.14 个百分点 |
| scl − ce | +0.09 个百分点 | -0.12 个百分点 |
| moco − ce | +0.32 个百分点 | +0.85 个百分点 |

- 只加 dropout：fold 0 三个种子的变化为 +1.72/+0.69/+0.22 个百分点，平均改善；但原方向 fold 0 几乎不变，dev 原方向下降，效果依赖推理方式，尚需跨折验证。
- R-Drop 对同 dropout 的 CE：fold 0 为 −2.71/−1.91/+0.62 个百分点，dev 为 +2.05/+1.70/−0.32 个百分点。不能因 dev 平均较高就选择 R-Drop。该对照检验 R-Drop 整体规则；它还改变双前向 CE 平均，因此不能把差异严格单独归因于 KL。
- SCL：fold 0 为 +1.08/+1.17/−1.99 个百分点；平均接近 CE，但种子波动更大。不能用只含前两个种子的阶段性包宣布提升。
- MoCo：fold 0 为 +0.42/+0.57/−0.02 个百分点，dev 三个种子都升。它是当前值得保留的候选，但提升较小，不能保证跨折泛化。

SoftCons、HardCons 与 WF1 均需报告，不用一致性替代正确性。完整三项指标、概率、预测、选轮记录在各方法目录；配对家族重抽样见[实验登记表](../../实验登记表.md)。这里的方法排序只针对当前 fold 0，不用于修改已有运行的超参数。

## 核验和运行成本

独立核验累计 629 项检查、84 份官方评分复算全部通过（15 个正式运行和 6 个真实 SMOKE 运行）。检查包括数据哈希、家族划分、概率与预测、官方评分、内层验证选轮及汇总。模型权重未在结果包内，适配器重载一致性依据运行记录，未重新加载完整权重。

MoCo 的每轮更新数为 137/274/411，队列填充数为 2190/4096/4096；独立模拟入队和 FIFO 年龄，与保存的计数一致。它只能核对日志层面的更新，不能代替目标权重或完整队列张量的复验。MoCo 对比损失受候选键数量影响，不凭它的绝对值与 CE/SCL 比较，也不据此临时调系数。
