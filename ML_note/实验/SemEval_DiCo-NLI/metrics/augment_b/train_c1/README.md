# 实验 B Commit 1：类别加权、原数据重复和类别构成的对照

mDeBERTa-v3-base CE（第五组 C0 配方），英语按家族五折 × 种子 42–44，Kaggle T4 x2、fp16，10 组共 150 项，全部用原数据，不含生成数据。用途有三：类别加权（W2 / W4）本身是一组比较；step+2 / step+4 是 Commit 2 里 B2 / B4 的同步数对照；Dup×5 是 G×5 的匹配对照（同一类别构成，只差多出来的那份是生成数据还是原数据的重复）。

| 组 | 训练数据 | 每折行数 |
|---|---|---|
| B0 | fit | fit |
| W2 / W4 | fit；loss 里 O 的权重 λ = 2 / 4（`w_O = λ/Z`，其余 `1/Z`，`Z = 1 + (λ−1)·p_O(fit)`，总体尺度不变） | fit |
| step+2 / step+4 | fit 每行重复 3 / 5 次 | 3·fit / 5·fit |
| Dup-U4 / BAL / E1 / D1 / O1 | fit + 按 `mixquota-v1` 的构成从 fit 重复采样 | 2·fit |

## 结果

Claude 用 `code/claude_recheck_augb_c1.py` 从每个任务的四类概率重建，150 项核对 0 个问题（哈希、选轮、步数、各组的行数和重复次数、W 的类别权重、Dup 的重复清单和 Commit 1 包里的 `mix_lists.json` 逐行一致）。结果包里没有训练脚本的汇总，分数只有这一份重建。

**v3 代码和 +1 的 v2 代码在 B0 上逐条相同**：三个种子的对称化预测 100% 一致，分数也完全一样（sym WF1 79.37%）。

- **类别加权**：λ = 2 没有作用；λ = 4 升了 O 的 F1（+2.0）和 sym WF1（+0.78），但区间含 0。推理时把 O 的 logit 减 log 4、撤掉权重造成的先验偏移后，W4 反而略高（+0.91），区间下限刚过 0。所以 W4 的增益不只是 O 的判定阈值移动；但这不说明模型的排序能力提高了（GPT 11-01 的更正）。四个主比较没有做多重比较校正，这个刚过线的结果要谨慎看。
- **原数据重复**：重复一遍（step+1）就有 +1.2 个百分点，重复三遍、五遍不再升（step+2 80.71%，step+4 80.55%）。这说明在固定 12 轮的配方下，多出来的更新次数在 +1 之后基本饱和；B2 / B4 是否有效，要看它们对 step+2 / step+4。
- **类别构成**：只改变重复采样的类别比例，没有一个构成显著好于按原比例重复（Dup_R）；U4（四类均等）显著更差。E1（多重复 E）最高，但对 Dup_R 区间含 0。这些是描述，生成数据在不同构成下的效果要等 Commit 2 的 G×5 对比同构成的 Dup。

## 问题

- **Dup_R 来自 +1 的 v2 代码**：Commit 1 没有单独跑 Dup_R，沿用 +1 的 step+1。v3 和 v2 在 B0 上逐条相同，但 v3 的重复采样路径没有和 v2 的 step+1 逐条对过，所以 Dup_c − Dup_R 只作描述。
- **区间不包含重新训练的随机性**：重抽样只抽家族。W2、W4 和 Dup 组的逐种子差符号常常不一致（种子 43 多为负），说明种子间波动和效应同量级。
- **fp16 跳步**：每组 15 项合计跳过 46–64 次更新（每项约 3–4 次），只报告。
- **选中轮**：B0 平均第 8.8 轮，W4 第 10.4 轮，step+4 第 6.7 轮。行数越多越早选中，加权越重越晚，只报告。
