事先定的读法（写在脚本开头，看结果后不改）：

- **R1**：S1 里两人一致但不等于金标的比例 a1 ≥ 50%，且比 S3 的同一比例高 30 个百分点以上，就说明顽固错误多是对照参考卡也复现不了的标法，后续改动不以它们为目标；S1 里两人一致且等于金标 ≥ 50%，就说明人能判出、模型全错，作为后续改动的目标；都不满足只报告。
- **R2**：某个现象在 S1 ∪ S2 里被两人同时标出 ≥ 6 个家族，且其中 ≥ 70% 两人一致且等于金标，列为定向增广候选（另行登记方案）。
- **R3**：金标 O 的家族里 O 子类的分布，供 Other 潜在分量头解读。

## 问题

- 48 个家族只够看出大的差别。比例都附计数，这是诊断，不改任何已登记的结论。
- Claude 不是完全盲的：更早的会话里零散看过的训练样例没法逐条排除；Codex 能读仓库，官方训练集也是公开的。两人都约定不查训练集和 OOF。
- 两个审阅人都知道这次抽样偏向模型的错误，可能影响判断。S3 对照用来衡量这种影响之外的基线分歧。
