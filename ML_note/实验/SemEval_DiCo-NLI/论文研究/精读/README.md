## 怎么读一篇论文：三遍法

来自 Keshav 的 *How to Read a Paper*（2007），按我们的情况改过。不要从第一页逐字读到最后一页：每一遍读的范围和目的都不同，前一遍决定值不值得读下一遍。

| 遍数 | 时间（第一次精读，可以放宽） | 读什么 | 读完要能回答 |
|---|---|---|---|
| 第一遍：看全貌 | 15–20 分钟 | 标题、摘要、引言的最后一两段、各级小节标题、图表和表格的标题、结论。正文先不读。 | ① 这是哪一类论文（提方法、提数据集、提评测、做分析）？② 它要解决什么问题（一句话）？③ 它声称的贡献有几条？④ 和我们的任务是什么关系？⑤ 值不值得读第二遍，为什么？ |
| 第二遍：看懂内容 | 1–2 小时 | 方法和实验，重点看图和表：坐标轴、对比的是谁、提升有多大、有没有方差或多次运行。推导先跳过。 | 方法论文：把方法画成数据流——输入是什么、算了什么、输出是什么（形状）、损失是什么、哪些参数被更新，并用一个小数字例子走一遍。实验：主表的结论是什么、对照是谁、数字可不可信。不懂的词全部列出来。 |
| 第三遍：看透 | 2 小时以上，可以分几次 | 合上论文，自己复述一遍；再回去逐条找作者没明说的前提。 | ① 不看论文，用自己的话把核心想法讲清楚。② 它依赖哪些假设？③ 每个假设在我们的数据上成立吗（能用仓库已有的输出检查的，交给 Claude 查）？④ 从不成立的假设、局限或错误分析里，能提出什么想法？每个想法配一个对照实验。 |

每一遍结束，Claude 出 1–3 道检查题，题目自带需要的数字和上下文。

## 怎么从论文里找到可以做的想法

读懂一篇论文和从中找到可以做的事是两回事。下面五种问法都能落到我们的实验上：

1. **找不成立的假设。** 论文的方法总有前提，前提在我们数据上不成立的地方就是机会。例：加权软标签蒸馏假设教师的软标签"诚实"；我们的教师在学生训练行上准确率 94–98%，几乎记住了答案，于是想到"交叉拟合教师"——这只是待检验的想法，教师尖锐不等于它就是蒸馏持平的原因。
2. **迁移到任务特有的结构上。** 我们的任务有方向：对调两侧，F 和 B 互换、E 不变。例：R-Drop 让同一输入的两次前向接近，换成"让 p(A, B) 和对调后的 p(B, A) 接近"就是方向版 R-Drop。
3. **读局限和错误分析。** 作者自己承认的问题，常常就是下一步。例：试点论文说主要混淆是"蕴含 ↔ 相似"。
4. **把两篇论文放在一起。** 一篇提出问题，另一篇有工具。例：数据地图能找出难学样本，可以用来筛实验 B 的生成数据。
5. **先估上限，再动手。** 想法针对的错误占多少、全修好最多涨多少（切片 oracle），值不值得花算力。

最后都要回到导师的原则：任何想法都要有实验支持——和基线对照，一次只改一处，跑多个种子，差值盖不过波动就不下结论。

## 读论文时容易犯的错

- 把摘要里的数字当结论：先看是和谁比、在什么设置下比、有没有多次运行。
- 把论文的设置当成我们的设置：数据规模、标签定义、模型大小不同，结论不一定搬得过来。
- 读懂了不等于会用：能复述是第一步，能说出它在我们数据上会不会成立才算读透。
- 被"新"吸引：新方法不一定比简单的基线好，要实验说话。

## 每篇的记录格式

每篇一个文件，读到哪写到哪：

1. **基本信息**：标题、作者、出处、链接；为什么现在读（对应哪类错误或哪个实验）。
2. **第一遍**：五个问题和我的回答。
3. **第二遍**：方法的数据流（带小数字例子）、关键图表的结论、不懂的词和解释。
4. **第三遍**：我的复述；依赖的假设，以及在我们数据上是否成立。
5. **阅读表**：解决的问题 / 核心想法 / 依赖的假设 / 在我们数据上是否成立 / 对应哪类错误 / 验证用的小实验和算力。
6. **检查题与我的作答**：题目 | 我的作答 | 判定与要点。
7. **对 SemEval 的启发**：产出的实验想法和对照设计；要跑的实验交回 SemEval 对话。
8. **易混点**。
