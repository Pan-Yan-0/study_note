## R1：O 的子类诊断

- **问题**：我们 O 边界上的错误集中在哪个子类（相反 / 相似 / 相关 / 无关）？试点论文说主要混淆是"蕴含 ↔ 相似"。
- **做法**：把训练集的 478 行 O 按文本对齐到 PhrasIS 原数据，取原标签；统计每个子类的召回率和被判成什么。只用训练集和已有 OOF，不碰 dev，不用于训练。
- **前提**：AGENTS 记录"PhrasIS 原数据能不能拿来训练，以官方最终规则为准"。只做诊断是否也要等，请 Pan-Yan-0 决定；也可以先问主办方。
- **产出**：子类 × 预测的表；决定 E3 的生成重点（如果"相似"占大头，就重点生成同类不蕴含的短语对）。

## R2：全错行的三方盲审

- **问题**：10 次 mDeBERTa 运行全错的 274 行里，多少是标注口径、多少是合理分歧、多少疑似错标、多少是模型确实没学会？
- **做法**：按家族抽 40–50 个（四类金标分层），隐藏金标和模型预测，Claude、GPT 各自独立判四分类并写一句理由；Pan-Yan-0 裁决分歧，再对照金标，归入四类之一。沿用第二组盲审的流程和表格格式。
- **注意**：这些行是用 OOF（留出折）选出来的，结果只用于理解错误，不用来删训练样本（否则留出折标签进入训练选择）。E2 用的是训练部分内部的训练动态。
- **判断**：如果"口径"类占多数 → 加强 E3；"合理分歧"多 → 考虑 E4；"疑似错标"多 → 只记录，不改金标。

## E1：交叉拟合教师的 KD

- **问题**：KD 和 CE 打平，会不会是因为教师在学生训练行上过拟合、软标签没有暗知识？（候选解释，未验证）
- **依据**：15 份教师在 fit 行上准确率 94–98%，金标概率中位数 .98–.999；同配方 Qwen 的 OOF 准确率约 85%（[assumption_checks.json](results/assumption_checks.json)）。
- **唯一改变的变量**：教师概率的来源。现在是"在全部 fit 行上训练的 Qwen 对 fit 行的输出"；改成"fit 行内部 4 折交叉拟合，每行的概率来自没见过它的模型"。学生配方、alpha = 0.5、T = 2、种子、划分都不变。
- **对照**：同 fold 0、同种子的现有 KD（JOINT 那一轮）和 CE；同一平台（A10，bf16）。
- **防泄漏**：内层 4 折只在 fold 0 的训练部分里分（按家族），fold 0 的留出行不进任何教师。
- **已知的混杂**：内层教师只用约 3/4 的训练行，教师本身更弱。分不开"诚实"和"更弱"两种影响，结论要写成"交叉拟合教师在给定设置下是否更好"。记录内层教师的 OOF 准确率，必要时加一组"同样 3/4 数据、但仍在训练行上导出"的对照。
- **判断规则（事先定）**：fold 0 三个种子，sym WF1 同种子差（交叉拟合 KD − 现有 KD）平均 > 0，且按家族配对重抽样区间下限 > 0，才扩到五折；否则记为"不支持"。同时报告 plain。
- **算力**：内层 4 折 × 3 种子 = 12 次 Qwen3-4B LoRA SFT（3 轮，每次在 A10 上约 15–18 分钟）+ 导出 + 3 个学生，合计约 4 小时、约 28 计算时。先跑 SMOKE。
- **零成本的前置检查**：交叉拟合后，教师在 fit 行上的准确率和 T = 2 熵应接近 OOF 水平（约 85%）；如果仍然很高，先排查是否有泄漏。

## E2：数据地图——去掉难学样本 vs 随机去掉

- **问题**：训练部分里"难学"的少量样本（可能是口径特殊或错标）是在帮忙还是在拉偏边界？
- **做法**：
  1. 记录用训练：mDeBERTa CE 配方，fold 0 × 3 种子，每轮结束记录训练部分每行的金标概率（需要在训练循环里加一个记录，代码由 SemEval 对话改）。
  2. 按信心（各轮金标概率均值）和变异度分区，取信心最低、变异度低的 5%（约 110 行）为"难学"。
  3. 两组各 3 种子：去掉难学的 5%；对照组随机去掉同样多的行（按家族去，保持标签比例）。
- **唯一改变的变量**：去掉哪些行。
- **判断规则**：sym WF1 同种子差（去难学 − 随机去）平均 > 0 且区间下限 > 0 才算支持；还要和不去任何行的 CE 比，确认不是"少训练数据"本身的影响。只有 3 个种子、约 110 行，结果不显著就记为"分不出"。
- **算力**：12 次 mDeBERTa 训练，A10 上每次约 2–3 分钟，合计约 40 分钟（约 5 计算时）；T4 约 1.5–2 小时。
- **后续用途**：如果有效，可以用同样的地图筛实验 B 的生成数据。

## E3：实验 B 的生成提示按标注口径写

- **问题**：生成数据如果按"严格逻辑蕴含"或 WordNet 层级造，会和金标口径冲突，反而教坏粒度判断。
- **依据**：金标的"蕴含"更接近 iSTS 的"更具体 / 更详细"；WordNet 下位词常被标成 E；复数蕴含单数、大数蕴含小数；不同数字的读数、互斥方位是 O；O 是相反 / 相似 / 相关 / 无关四类合并，主要难点是"相似"。
- **建议的改动**（给实验 B 的生成提示，需和 GPT 讨论后修订冻结计划）：
  - 在提示里写明口径和来源（"从训练数据和 PhrasIS / iSTS 指南归纳"），按论文写明外部数据的要求留档；
  - O 的生成按子类分配，重点生成"同类但不蕴含"的对（相似），而不是大量"完全无关"的对（模型已经很会分）；
  - 粒度上专门生成"近义说法、同一所指的不同称呼 → E"和"多一个细节 → 单向"的成对样本，避免"等价全是动作、单向全是上下位名词"的模板偏差（已有的担心）。
- **算力**：不增加训练；生成侧由 Claude 写。是否改冻结计划由 Pan-Yan-0 和 GPT 讨论决定。

## E4：软标签训练（可选）

- **问题**：在有合理分歧的样本上，降低模型的过度自信能否改善 O 边界？
- **前提**：只有 R2 显示"合理分歧"占比高时才做。
- **唯一改变的变量**：CE 加标签平滑 ε = 0.1。对照：同 fold 0、同种子的 CE。
- **判断规则**：同 E2。
- **算力**：mDeBERTa fold 0 × 3 种子，A10 约 10–20 分钟。
- **说明**：评测仍是单一金标，这个实验检验的是"降低过度自信"，不是拟合人的分布（第 4 篇）。

## 不建议现在做

- **WordNet 关系特征（KIM 类）**：实词单词替换 196 对里 WordNet 能定关系的只有 73 对，其中 44% 和金标口径冲突；单词替换整个切片的 oracle 上限也只有 +.051（英语）。等 R2 和 R1 的结果再说。
- **直接上 WSL（加权软标签）**：前提是教师软标签诚实，现在不成立；应在 E1 之后再考虑。
