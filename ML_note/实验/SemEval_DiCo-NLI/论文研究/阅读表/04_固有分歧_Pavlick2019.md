# Pavlick & Kwiatkowski 2019：Inherent Disagreements in Human Textual Inferences

TACL 7，2019（Q19-1043）。

## 阅读表

| 项目 | 内容 |
|---|---|
| 解决的问题 | NLI 标注者之间的分歧，是能靠多数票消掉的噪声，还是可复现的、本来就该保留的信号？ |
| 核心想法 | 从 RTE2、SNLI、MNLI、JOCI、DNC 各取 100 对，每对请 50 人在 −50 到 50 的滑条上打分。如果分歧是噪声，分数应是单峰高斯；用留出似然比较单高斯和高斯混合，看混合模型能否泛化到没见过的打分。再拿 BERT 的 softmax 和人的分布比。 |
| 依赖的假设 | ① 噪声是单峰的；② 50 个众包标注者能代表"人"；③ 把滑条分成三类后能和三分类模型比。 |
| 在我们数据上是否成立 | 我们没有多人标注，不能直接检验。间接证据：10 次 mDeBERTa 运行全错的 274 行里，191 行错成同一个标签，163 行 Qwen 三个种子也全错；盲审里两人意见一致却和金标不同的有 11 个家族。这符合"系统性分歧"，但分不开"标注口径"（第 2 篇）、"固有分歧"和"错标"。 |
| 对应哪类错误 | 共同错误（O 边界和粒度里，各模型都错且错得一样的那部分）。 |
| 验证用的小实验和算力 | R2：从 274 行全错行里按家族抽样，Claude、GPT 各自盲标，再由 Pan-Yan-0 裁决，分成"口径 / 合理分歧 / 疑似错标 / 模型确实错"四类（无 GPU，人工约 1–2 小时）。E4（可选）：只有在 R2 显示"合理分歧"占比高时，才试软标签训练。 |

## 三遍法笔记

### 第一遍

- 类型：数据分析论文，不提出模型。
- 结论：约 20% 的句对有明显的第二个峰；给更多语境，分歧不减反增；BERT 的 softmax 和人的分布对不上。

### 第二遍

- **筛选**：509 名标注者，去掉相关性异常的 14 人和有效标注太少的 37 人；留下 496 对，平均每对 39 个打分；每人按批次标准化。
- **检验**：10 次随机划分，比较单高斯和变分高斯混合的留出对数似然；大多数点在 y = x 线上或上方，混合模型多出来的成分能泛化。
- **语境实验**：300 个维基百科里的替换词（上位、反义、同位），分词、句、段三种语境；方差 .34 → .41 → .56，语境越多分歧越大。
- **模型**：BERT 在各数据集上微调，只看原标签、新多数标签和模型预测三者一致的对；期望交叉熵 .03，实际 .37。softmax 的信心主要反映数据集层面的偏差，不反映单个样本上人的不确定。
- **建议**：评测时用对人类分布的交叉熵；测试集要多人标注；训练要么收分布，要么设计能从单标签学不确定性的目标。

### 第三遍

- **复述**：作者用"能不能泛化到新打分"来区分噪声和固有分歧，这比只看一致性系数更有说服力。结论是：单一金标在约五分之一的样本上抹掉了真实的分歧。
- **和我们的对照**：
  - 他们的语境实验里，替换词（上位、反义、同位）也有明显分歧——这和我们单词替换的难点是同一类现象。
  - 我们的共同错误高度一致（同一个错误标签），这既可能是"人也会这样判"，也可能是"模型都学到了同一个表面线索"（如"低重合 → O"）。论文的方法要多人打分才能区分，我们做不到 50 人，只能用三个人的盲审做粗分。
- **对我们的启示**：
  1. 评测是官方金标，单标签，我们不能改；所以软标签训练的目标是"别让模型在有分歧的样本上过度自信、拉偏决策边界"，不是去拟合人的分布。
  2. 这类样本不该被当成"越多越好"的训练信号，也不该在扩充数据时按同一模板大量复制。
  3. 盲审结果写报告时，应说成"审阅判断和金标的分歧"，不说"金标错了"——这和仓库现有的约定一致。
- **存疑**：他们的数据是句子级 NLI，标注方式是非规定性的（让众包凭直觉）；PhrasIS 是专家按指南标的，分歧更可能来自口径而不是直觉差异。
