# MacCartney & Manning 2009：An Extended Model of Natural Logic

IWCS 2009。DiCo 提案说标签体系"基于自然逻辑式的细粒度推理标签"，引的是 MacCartney 2009 的博士论文；这篇是它的核心部分。

## 阅读表

| 项目 | 内容 |
|---|---|
| 解决的问题 | 不翻译成一阶逻辑，直接在自然语言表面上做推理：前提经过一串编辑变成假设，判断两者的语义关系。 |
| 核心想法 | 七种基本关系：等价 ≡、前向蕴含 ⊏、后向蕴含 ⊐、否定 ^、交替 \|（互斥但不穷尽，如 cat \| dog）、覆盖 ‿、独立 #。每个原子编辑（替换、插入、删除）先得到一个词汇关系，再经过上下文的单调性"投射"，最后把各步关系"合并"。替换的关系可以查 WordNet：同义 → ≡，下位 → 上位是 ⊏，反义和同位词 → \|。删去交集性修饰语得 ⊏，插入得 ⊐。 |
| 依赖的假设 | ① 表达式非空；② 词汇关系能从词典稳定得到；③ 每步编辑的关系可组合；④ 蕴含是集合包含（严格逻辑），不是"更具体"。 |
| 在我们数据上是否成立 | ②④ 只部分成立。实词单词替换 196 对里，WordNet 有明确关系的 73 对，金标符合自然逻辑映射的 41 对（56%）。偏离的方向很有规律：WordNet 下位词标成 E（A guy ‖ A man、A large jet ‖ A large airplane、a collection ‖ A group）；上位词有 5 对标 E、6 对标 O；同位词（应为 \|，归 O）里有数字被标成蕴含（Four dead ‖ Five dead → B，Three dogs ‖ Two dogs → F）和 on a mountain ‖ on a hill → B。插入类遵循"删修饰语得蕴含"的规则准确率很高（早期统计：长度规则在训练集对 87%），这部分假设成立。 |
| 对应哪类错误 | 粒度（E ↔ 单向）、单词替换；O 的子类（交替 / 独立对应 PhrasIS 的相反 / 相似 / 相关 / 无关）。 |
| 验证用的小实验和算力 | 已做的离线检查：[assumption_checks.py](../code/assumption_checks.py) 第 1 部分（CPU，几秒）。结论是不建议把 WordNet 关系直接当特征或规则（见第 7 篇）。 |

## 三遍法笔记

### 第一遍

- 类型：理论 + 系统论文。给出关系代数、投射规则和合并表，在 FraCaS 和 RTE3 上评测。
- 结论：FraCaS（不含多前提）平均准确率 70%、精度 89%，自然逻辑相关的五节 87%；RTE3 单独 59%，加进 Stanford RTE 系统后提升约 4 个百分点。

### 第二遍

- **关系定义**（集合论）：≡ 是 x = y；⊏ 是 x ⊂ y；^ 是不相交且并为全集；\| 是不相交、并不为全集；‿ 是相交且并为全集；# 是其余情况。
- **原子编辑**：专有名词同一实体为 ≡，不同实体为 \|；难判断的默认 #；"former"这种非交集形容词，删掉得 \|，"alleged"删掉得 #。
- **投射**：上行单调保持 ⊏ / ⊐，下行单调互换，非单调变 #；"no"两个论元都下行，"every"第一个论元下行。
- **合并**：49 种组合里 32 种得到基本关系，其余是并集关系，实现里近似成 #——推理链越长越容易变成"不知道"。
- **局限**：编辑序列要从别处得到；没有多前提；编辑顺序可能影响结果，没有正式的可靠性保证。

### 第三遍

- **复述**：把蕴含当成"集合包含"，用词汇关系 + 单调性计算短语关系。DiCo 的 E / F / B 就是这里的 ≡ / ⊏ / ⊐，O 则把 ^、\|、‿、# 合成一类。
- **在我们数据上**：
  - 短语很短（平均 3 个词）、几乎没有否定和量词（训练集 1,760 对里否定 5 对、量词 33 对），所以投射和合并基本用不上，起作用的只有"原子编辑的词汇关系"。
  - 插入类符合"删修饰语得蕴含"，模型在这里已经 .95 以上，没什么可改。
  - 单词替换才是难点，而金标在这里按"更具体 / 同一所指"标，和 WordNet 的严格层级冲突（见上表）。
- **对我们的启示**：自然逻辑给了一个好的错误分类框架（O 内部可以按 ^ / \| / # 细分），但它的严格蕴含假设和 PhrasIS 口径不一致，不能当"正确答案的规则"。用它的地方应是诊断和生成数据时的分类提示，而不是特征。
- **存疑**：我们的 WordNet 检查只取第一个能匹配的词形，没做词义消歧；"上位 / 下位"取全部义项的闭包，会把多义词的远关系也算进去。所以 56% 是粗口径，方向上可信，具体数字不宜引用为精确值。
