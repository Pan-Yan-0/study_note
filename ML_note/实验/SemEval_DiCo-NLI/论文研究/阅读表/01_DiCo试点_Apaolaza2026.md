## 三遍法笔记

### 第一遍（标题、摘要、引言、小节标题、结论）

- 类型：评测论文，提出一种度量（SoftCoh / HardCoh），不提出模型。
- 背景：把"反转诅咒"推广成一般的方向一致性问题。
- 结论：编码器（尤其 DeBERTa-v3）最好；方向一变，所有模型都掉分；解码器掉得最多。
- 和我们的关系：这就是 DiCo-NLI 的前身，SoftCons / HardCons 的定义来自这里。

### 第二遍（图表、实验设置、错误分析）

- **数据**：PhrasIS 一万多对短语，七个标签：等价、前向 / 后向蕴含、相反、相似、相关、无关。分"Positives"（不含无关）和"All"两个赛道，来源分图片描述（I）和新闻标题（H）。
- **设置**：每个模型用 Optuna 搜 150 组超参（A100），80/20 划分选模型后用全部训练数据重训。
- **结果（表 3，weighted F1）**：DeBERTa-v3-base 在 Positives 上 I / H / A 是 .73 / .73 / .75，在 All 上 .87 / .88 / .88。All 一直比 Positives 高，作者认为"无关"类很容易分。这个任务是七分类，和我们的四分类不能直接比。
- **一致性（表 4–7）**：seen 的 SoftCoh 很高（DeBERTa .93–.98），unseen 掉 .10–.20；HardCoh 再低几个点。H 比 I 难。
- **错误分析（4.2 节、5.2 节）**：
  - DeBERTa 的主要混淆是"蕴含 ↔ 相似"，"相关"容易分；
  - 新闻标题上有词汇重合时偏向预测"相似"；
  - 多数难例含介词，两边介词不同时预测接近随机；
  - 近义和上下位知识不够："rally ↔ march"判成相似；"a black dog ↔ the German shepherd dog"判成相似而不是蕴含；
  - 公众人物："Pope Francis ⇒ pope"常被判成等价。
- **附录 A.1 标签定义**：相似 = 属于同一语义类别，但不等价、不蕴含、不相反；相关 = 有弱的语义联系，不够"相似"。量词的方向：someone 比 everyone 更一般（everyone → someone 是蕴含）；复数蕴含单数（women ⇒ woman）。

### 第三遍（复述、找假设、和我们的数据对照）

- **用自己的话复述**：作者想说明"方向一致性"是独立于准确率的能力缺口，于是在 PhrasIS 的可对调子集上把每对都对调一次，用两个比率分开度量。实验结论可信的部分是不同模型族的相对排序；"浅层模式匹配"这一解释没有直接证据，主要来自人工看错例。
- **隐含假设**：错误都算模型的错。但附录本身给出的口径（复数蕴含单数、量词方向反直觉）说明，有些标签要靠学"口径"才能对。我们的 WordNet 检查也看到：实词单词替换里复数 / 数字被标成蕴含、下位词被标成等价的情况不少。
- **对我们最有用的三点**：
  1. DiCo 的 O = 相反 + 相似 + 相关 + 无关（提案第 3.1 节写了"PhrasIS 中这个代数之外的标签都并入 NEGATIVE_OTHER"，并且做了截断和分层）。我们的 O 边界错误很可能主要是"相似"。
  2. 复数蕴含单数、大数蕴含小数（"22 dead / 89 dead"标成后向蕴含）是口径，和我们训练集归纳的计数规则一致。
  3. 作者建议"按泛化差距选模型、加强正则、针对主要混淆做定向扩充"，和我们的实验 B 方向一致；定向扩充应该集中在"相似"这种同类不蕴含的对上。
- **不同意或存疑的地方**：表 3 用了 150 组超参搜索再挑"泛化差距小的"，选模型过程有人工判断，分数不宜当作强基线；"词汇重合多就偏向相似"在我们数据上不成立（可能因为我们的 O 是四类合并，模型学到的是"低重合 → O"）。
