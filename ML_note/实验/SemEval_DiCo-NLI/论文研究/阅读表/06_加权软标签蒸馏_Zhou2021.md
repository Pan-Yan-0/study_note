# Zhou et al. 2021：Rethinking Soft Labels for Knowledge Distillation: A Bias-Variance Tradeoff Perspective

ICLR 2021（arXiv:2102.00650）。

## 阅读表

| 项目 | 内容 |
|---|---|
| 解决的问题 | 蒸馏的软标签什么时候帮忙、什么时候拖后腿？能不能按样本调节蒸馏强度？ |
| 核心想法 | 把 KD 损失写成 L_ce + (L_kd − L_ce)：前一项主要降偏差，后一项主要降方差。在真实类别的 logit 上，如果第二项的梯度大于第一项，这个样本就是"正则化样本"，蒸馏在它上面以降方差为主、会增加偏差。于是给每个样本的蒸馏损失乘权重 1 − exp(−L_ce^学生 / L_ce^教师)（都在温度 1 下算）：学生已经比教师拟合得好的样本，权重小。 |
| 依赖的假设 | ① KD 的方差不大于直接训练（经验假设，用校准和对抗一致性支持，没有证明）；② 教师在训练样本上的输出是"有信息的软标签"，教师和学生的损失之比能反映谁估计得更好；③ 教师固定、不过拟合训练集。 |
| 在我们数据上是否成立 | ② ③ 看起来不成立（数字实测，解释是推断）。15 份教师在学生训练行（fit）上的准确率 94–98%，金标概率中位数 .98–.999，81–94% 的行超过 0.9；而同配方 Qwen 的 OOF 准确率约 85%。教师见过这些行，在上面过拟合，L_ce^教师 几乎处处接近 0，WSL 的权重在绝大多数行上都接近 1，方法退化成普通 KD。T = 2 软化后的平均熵只有 0.33–0.69 nats（四类均匀分布是 1.39）。 |
| 对应哪类错误 | KD 修正和新增错误互相抵消（修正 91、新增 88，类型分布几乎一样）。 |
| 验证用的小实验和算力 | E1：交叉拟合教师——在 fold 0 的训练部分内部再分 4 份，每份用其余 3 份训练 Qwen，导出它没见过的那份的概率，拼成全部训练行的"诚实"软标签；学生配方、alpha、T 都不变，只换教师概率的来源。fold 0 × 3 种子。Qwen 4B 在 A10 上 3 轮约 18 分钟一次，12 次约 3.5–4 小时，加 3 个学生约 10 分钟，合计约 28 计算时。先做一步零成本检查：交叉拟合后教师在训练行上的准确率和熵是否接近 OOF 水平。 |

## 三遍法笔记

### 第一遍

- 类型：分析 + 小方法（WSL）。
- 结论：WSL 在 CIFAR-100 和 ImageNet 上稳定高于普通 KD；作者强调权重的具体形式"不是数学上最优"，贡献在于按样本调节的思路。

### 第二遍

- **设置**：CIFAR-100 用 τ = 4，ImageNet 用 τ = 2；α 通过网格搜索（2.25、2.5）。
- **结果**：WRN-40-2 → WRN-40-1：KD 73.54 → 74.48；ResNet-34 → ResNet-18：KD 70.67 → 72.04。
- **消融**：只在正则化样本上用 WSL 或只在其余样本上用，都有提升；教师用标签平滑训练时也有效。
- **NLP**：MultiNLI 的实验只在附录。
- **需要的信息**：金标类别、教师在金标类别上的概率；不需要单独的"教师对错"标记。

### 第三遍

- **复述**：蒸馏不是对每个样本都好。教师在一个样本上的损失相对学生越小，这个样本的软标签越值得学；反之应少学。
- **关键前提**：教师的软标签要"诚实"。论文里的教师在 ImageNet / CIFAR 上没完全记住训练集（训练准确率不到 100% 且有数据增强），而我们的 Qwen LoRA 教师在 2,000 多行上训了 3 轮，训练行准确率 94–98%，几乎是记住了。
- **对我们的启示**：
  1. 现在的 KD 打平，"教师软标签没有暗知识"是一个值得优先检验的候选原因；alpha、T、学生容量同样没有排除。
  2. 交叉拟合教师之后，WSL 这类按样本加权才有意义，可以作为 E1 之后的下一步。
  3. 之前 README 里"交叉拟合教师只有在诊断支持后再安排"，这次的教师置信度统计提供了支持安排它的线索，但不是它能起作用的证据。
- **存疑**：我们的统计按文本对去重匹配了 2,148–2,161 行（fold 训练部分约 2,190 行），少数文本相同的行被合并；准确率口径和之前 qwen_teacher 的检查（.969–.979，那是旧的 fold 0 教师）不完全一样，结论只用到"远高于 OOF 的 85%"这一层。
