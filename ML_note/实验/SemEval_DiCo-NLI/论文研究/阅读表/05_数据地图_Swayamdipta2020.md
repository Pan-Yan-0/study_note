# Swayamdipta et al. 2020：Dataset Cartography

EMNLP 2020（arXiv:2009.10795）。

## 阅读表

| 项目 | 内容 |
|---|---|
| 解决的问题 | 训练集里的样本作用不同：哪些容易、哪些模棱两可、哪些可能标错？怎么不靠人工就把它们分出来，并用来挑训练数据？ |
| 核心想法 | 训练时在每轮结束记录模型给金标的概率。信心 = 各轮均值，变异度 = 各轮标准差，正确率 = 各轮预测对的比例。画成二维图分三区：容易（高信心低变异）、模棱两可（高变异）、难学（低信心低变异）。难学区常是错标；只用三分之一的模棱两可样本训练，分布外泛化更好。 |
| 依赖的假设 | ① 训练动态在不同随机初始化下稳定（论文只在 WinoGrande 上测，相关 ≥ .75）；② 低信心低变异主要是错标；③ 数据量够大，丢掉一部分还能训好。 |
| 在我们数据上是否成立 | ① 未检验：我们没有逐轮记录训练行的概率，只有跨种子 OOF 的对错。用这个替代口径（CE + R-Drop 共 10 次运行），2,020 行全对、482 行多数对、266 行多数错、274 行全错。② 部分存疑：全错的 274 行里 191 行错成同一个标签，这符合"低信心低变异"，但第 2、4 篇说明其中很多可能是口径或合理分歧，不一定是错标；全错行里 O 占 32%，是训练集占比的两倍。③ 不成立：我们英语训练集只有 3,042 行，论文里 17% 以下的模棱两可子集在 WinoGrande 上就训不起来，所以只能考虑"去掉或降权少量难学样本"，不能"只用模棱两可样本"。 |
| 对应哪类错误 | 共同错误；另外可以给实验 B 的生成数据做筛选（找出生成样本里的难学区）。 |
| 验证用的小实验和算力 | E2：在 mDeBERTa CE 的训练循环里逐轮记录训练行的金标概率（只用训练部分，不碰留出折），按信心选出难学的 5%，对照组随机去掉同样多的行，fold 0 × 3 种子。约 9 次 mDeBERTa 训练 + 3 次记录用训练，A10 上每次约 3 分钟，合计约 40 分钟（约 5 计算时）；T4 约 1.5–2 小时。 |

## 三遍法笔记

### 第一遍

- 类型：分析 + 数据选择方法。
- 结论：大部分样本容易；模棱两可的样本对分布外泛化最有用；难学样本常是错标。

### 第二遍

- **设置**：RoBERTa-large，WinoGrande、SNLI 训 6 轮，MNLI、QNLI 训 5 轮，第一轮也算进统计。
- **错标检测**：在容易区随机翻转 1% 的标签再重训，被翻转的样本信心下降。只用信心的线性分类器，在 SNLI 上标出约 1.5 万个疑似样本；人工复核 100 个，被标出的 76% 是错标或歧义，没被标出的只有 4%（WinoGrande 是 67% 对 13%）。
- **只用 33% 数据训练（表）**：SNLI 全量 92.0 / 分布外 61.8；随机 33% 91.3 / 60.4；模棱两可 33% 92.2 / 63.5。MNLI、QNLI 规律相同。
- **成本**：要先在全量上训一遍；早停的训练动态和完整训练相关性好（没给具体数字）；小模型画出的图形状相似但区分不清。
- **局限**：分区依赖模型；去掉检测出的噪声对 WinoGrande 的成绩影响不明显；难学样本不全是错标。

### 第三遍

- **复述**：同一个样本在训练过程中被"学会"的方式，比最终对错更能说明它的性质。用这个信号挑数据，比随机挑更好。
- **和我们对照**：
  - 我们的跨种子替代口径只能区分"总是错"和"有时错"，分不出论文意义上的"模棱两可"（那需要同一次训练里各轮之间的摇摆）。
  - 而且 OOF 里的"全错"是在留出折上算的，用它来删训练样本会让留出折的标签信息进入训练选择，评测会偏乐观。所以正式做必须在每折的训练部分内部记录训练动态。
- **对我们的启示**：
  1. 先把难学区的样本拿给人看（和第 4 篇的 R2 合并），再决定是删、降权，还是写进口径说明。
  2. 实验 B 生成的数据量大时，可以用数据地图筛掉"难学"的生成样本——这比人工逐条盲审便宜，但要先用 E2 证明它在原始数据上有用。
- **存疑**：我们数据量小、标签只有四类，5% 只有约 110 行，3 个种子的差值可能盖不过波动；所以 E2 的判断规则要事先写好，结果不显著就记为"无法区分"。
