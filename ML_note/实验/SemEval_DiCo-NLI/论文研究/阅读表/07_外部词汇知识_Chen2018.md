# Chen et al. 2018：Neural Natural Language Inference Models Enhanced with External Knowledge（KIM）

ACL 2018（arXiv:1711.04289）。

## 阅读表

| 项目 | 内容 |
|---|---|
| 解决的问题 | 只靠训练数据，NLI 模型学不全词汇关系（如"国籍""国家"这类替换），Glockner et al. 2018 的"单词替换"测试集上掉得很厉害。 |
| 核心想法 | 给每对词算 5 维 WordNet 特征：同义、反义、上位（1 − 边数 / 8）、下位、同位，放进 ESIM 的三个地方：对齐注意力、局部推理特征、组合时的加权池化。 |
| 依赖的假设 | ① 任务的词汇关系和 WordNet 的严格层级一致；② WordNet 覆盖够；③ 训练数据越少，外部知识越有用。 |
| 在我们数据上是否成立 | ① 不成立：实词单词替换 196 对里，WordNet 有明确关系的只有 73 对，其中金标和"同义 → E、下位 → F、上位 → B、反义 / 同位 → O"一致的只有 41 对（56%）。② 部分：18 对至少一边查不到（如 airstrikes、ladies 这类复数和派生）。③ 成立，但我们的困难不在"没见过这个词对"，而在口径（第 2、3 篇）。按 WordNet 关系分组，Qwen 在"同义"上 .95、"上位"上只有 .51，CE 也只有 .58——"上位"组的金标本身就分散在 B、E、O 三类。 |
| 对应哪类错误 | 单词替换、粒度。 |
| 验证用的小实验和算力 | 不建议现在做。理由：能覆盖的样本少（单词替换的切片 oracle 上限英语 +.051，WordNet 能定关系的只占其中约三分之一），而且一半左右和口径冲突。若以后要试，最便宜的版本是把关系写成文本前缀（如 "[WN: hypernym]"）加进 mDeBERTa 输入，fold 0 × 3 种子，约 6 次训练、A10 约 20 分钟；但应先等 R2 的口径分类结果。 |

## 三遍法笔记

### 第一遍

- 类型：模型改进。
- 结论：SNLI 88.6%（ESIM 88.0%）；Glockner 测试集上 KIM 只掉 5.1 个点，ESIM 掉 22.3 个点。

### 第二遍

- **特征**：上位按距离衰减，超过 8 条边的忽略；试过 Jiang-Conrath 距离、15 种关系、TransE 关系向量，都没有进一步提升。
- **Glockner 分类别**：国籍 35.9 → 73.5，国家 25.4 → 70.8，饮料 63.7 → 96.6，反义 70.4 → 86.5；同义反而下降（99.7 → 92.1）。
- **数据量**：只用 0.8% 训练数据时，三处加知识合计从 62.4 升到 72.6；数据越多，知识权重 λ 的最佳值越小（20 → 0.2），全量时提升只剩 0.6。
- **MultiNLI**：领域内只 +0.4。

### 第三遍

- **复述**：外部知识在"测试词对没在训练里出现过、且词对关系就是 WordNet 关系"时最有用。Glockner 测试集正是按 WordNet 关系构造的，所以提升大。
- **和我们对照**：dev 的 90 个替换词对里只有 9 个在训练集出现过（早期错例分析），这一点像 Glockner 的设定，似乎有利于 KIM；但我们的金标并不按 WordNet 层级标（下位词常标 E，复数、数字按 PhrasIS 口径标蕴含），所以①这一前提不满足。另外 KIM 是 ESIM 结构，在 mDeBERTa / Qwen 上没有对应位置可以直接插特征。
- **对我们的启示**：预训练大模型已经带了大量词汇知识（Qwen 在"同义"组 .95），缺的是这个数据集的口径；所以针对口径的数据（实验 B 按口径生成）比外部词典更对路。
- **存疑**：我们的 WordNet 检查没做词义消歧，关系判断是粗口径（见第 3 篇的说明）。
