## 本轮结论

第六组同一份代码、A10 bf16、英语 fold 0、三个种子，对称化 WF1：

| 方法 | fold 0 | dev |
|---|---:|---:|
| CE | 85.25% | 82.68% |
| CE+dropout | 86.13% | 82.90% |
| R-Drop | 84.79% | 84.04% |
| SCL | 85.33% | 82.56% |
| MoCo | 85.57% | 83.53% |

只加 dropout 在 fold 0 的三个种子都提升，平均 +0.88 个百分点；MoCo 平均 +0.32 个百分点、波动较小。两者是后续跨折验证候选，不是已确定的最终方法。

R-Drop 与 CE+dropout 比，fold 0 低 1.33 个百分点而 dev 高 1.14 个百分点，不按 dev 挑选方法；且两者还差双前向 CE 平均，不能把差异严格单独归因于 KL。SCL 平均接近 CE，第三个种子明显下降。不要因为初步均值或单个种子好看继续扩大实验。

第五组 KD 已完成并且三个种子小幅提升，但平均仅约 +0.32 个百分点。现在的结论是“蒸馏初步有效信号较小”，不是“老师未做”，也不是“蒸馏失败”。跨折、跨语言的结论仍需对应实验。

## 可能的瓶颈与验证方式

1. **方向信息利用不充分**：多个方法依赖推理对称化才能取得更好的结果。先拆分交换方向前后的错误，区分被纠正和新引入的错误；第五组方向约束明显下降，不能直接加大方向损失。
2. **语义边界难区分**：此前错例集中于 NEGATIVE_OTHER 边界和单词替换。对当前五种 Qwen 方法统计共同错例、各类混淆和词语重合程度，再一起人工抽查。先验证是词义、关系、上下文或标注歧义，再设计困难样本或结构化关系表示。
3. **稳定性尚未验证**：一个 fold、三个种子不足以确定泛化改善。先冻结配方再增加留出折，不在看过各折结果后反复调参。
4. **蒸馏收益有限的原因未明**：老师在训练数据上的高准确率不能证明可迁移知识多；需要分析老师纠正了什么、学生是否继承，不能直接认定学生容量不足或温度不合适。
5. **控制变量还可细化**：SCL/MoCo 引入多项组件，成功或失败只能先归因于整套配方。需要解释机制时，再做有针对性的消融，避免一口气扫描大量系数。
