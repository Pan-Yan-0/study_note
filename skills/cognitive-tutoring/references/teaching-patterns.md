# 教学招式库（Teaching Patterns）

每个招式：是什么 → 何时用 → 实例骨架。

## 目录
1. 全流程地图　2. 脚手架填空　3. 调用链标注　4. 理论钩　5. 三遍法　6. 演进史四段式　7. 找不同练习　8. 苏格拉底追问　9. 先诊断后给药　10. 反直觉点爆破

## 1. 全流程地图
**是什么**：讲任何细节前，画出输入→处理→输出全局图，每环节标注「产出数据还是产出预测」。
**何时用**：新主题第一课；学生迷失在细节里时。
**实例**：评论文本 ─清洗→ 词列表 ─编码→ 索引矩阵 ─模型→ logits ─argmax→ 0/1 ─模板→ 提交CSV

## 2. 脚手架填空
**是什么**：任务描述 + 提示（该用哪个已学知识）+ 带 `____` 的骨架 + 折叠答案。学生填，不抄。
**何时用**：学生第一次写某类代码。

## 3. 调用链标注
**是什么**：每个函数旁标注：谁调用它 / 参数从哪一步的哪个变量来 / 产出给谁用。
**何时用**：任何含函数的教学。根治「这个函数是给谁用的」。

## 4. 理论钩
**是什么**：代码段旁挂「这行 = 课程第 N 集的哪个公式」，把 API 翻译成学生已学的理论语言。
**何时用**：学生上过理论课但「会用不懂理」时。
**实例**：`loss.backward() + optimizer.step()` = θ := θ − α·∂J/∂θ（15–20 集）。

## 5. 三遍法
**是什么**：第 1 遍跟写理解 → 隔天第 2 遍盲写骨架（允许查 API 名）→ 第 3 遍改造成相邻技术。
**实例**：「把 CNN 换成 LSTM，训练循环一行不许改」→ 理解模型与训练解耦。

## 6. 演进史四段式
**是什么**：当时的痛苦 → 核心洞察 → 思考方法 → 成功里埋下的失败种子（=下一代动机）。
**何时用**：技术族谱/发展史；学生问「为什么学这个老东西」时。

## 7. 找不同练习
**是什么**：故意不给新骨架，让学生从相似旧代码改出新技术。
**何时用**：新旧技术只有微小差异（GRU vs LSTM，答案一个单词）。

## 8. 苏格拉底追问
**是什么**：学生声称理解后，用可证伪的小问题验证。
**实例**：「为什么词索引从 1 开始？」（0 留给 PAD/unk，weight 第 0 行全零）。

## 9. 先诊断后给药
**是什么**：先区分问题在「理解层/操作层/环境层」，再决定讲解深度。
**实例**：提交失败 → 追到 quoting=3 保字面引号的数据层根因，再给模板法。

## 10. 反直觉点爆破
**是什么**：学生笔记中的错误记忆/公式，显式标记「⚠️ 记错了」+ 正确版 + 验证例子。
**何时用**：整理口述笔记时发现的每一处错误。不委婉，不错过。
**实例**：F1 记成 PR/2(P+R) → 纠正 2PR/(P+R)，用 P=1,R=0.1 验证。
