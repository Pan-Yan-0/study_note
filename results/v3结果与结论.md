# v3 全量结果与结论（DeBERTa-v3-large + 集成 + v2 结论补验）

运行信息：
- 总用时 3.8 小时，无报错。
- 验证集按源视频对半分：选择区 VS 332 条（119 个视频），校准区 VC 396 条（120 个视频）。
- VC 没有参与 DeBERTa 的任何选择，是对 DeBERTa 的诚实留出估计。

## 一、性能：DeBERTa 明显优于 BERT

| 模型 | 集合 | 宏 F1 | 加权 F1 | Acc-3 | MAE | Corr |
|---|---|---|---|---|---|---|
| BERT base（5 种子均值） | 验证（全部 728 条） | 0.620 | 0.641 | 0.641 | 0.567 | 0.685 |
| DeBERTa 单模型（5 种子均值） | 验证 | 0.673 | 0.693 | 0.692 | 0.503 | 0.765 |
| DeBERTa 5 种子集成 | 验证 | 0.686 | 0.705 | 0.703 | 0.481 | 0.782 |
| DeBERTa 5 种子集成 + 规则层 | VC | 0.692 | — | 0.715 | 0.472 | — |
| DeBERTa 5 种子集成 + 规则层 | 测试 | 0.697 [0.661, 0.732] | — | 0.735 [0.701, 0.769] | 0.538 [0.502, 0.575] | 0.785 |
| DeBERTa 单模型 s17（事先定好的部署种子） | 验证 / VC / 测试 | 0.675 / 0.676 / 0.694 | 0.697 / — / 0.729 | 0.699 / 0.705 / 0.732 | 0.496 / 0.495 / 0.542 | — |

- 方括号是按源视频重抽样的 95% 区间。
- **与 BERT 的配对比较（测试集，按视频重抽样）：**
  - DeBERTa s17 − BERT s17：宏 F1 +4.9 [1.3, 8.4] 个点，Acc +3.9 [0.6, 7.0] 个点，MAE −0.070 [−0.103, −0.037]。
  - 集成对集成，在 VC 上：宏 F1 +6.6 [1.0, 11.8] 个点，MAE −0.072。
- **目标对照：**
  - Acc ≥ 0.70：集成在验证、VC、测试上都达到。
  - MAE < 0.60：全部达到，0.47–0.54。
  - 宏 F1 ≥ 0.70：集成差 0.3–1.4 个点，单模型差约 2.5 个点。
  - 加权 F1 ≥ 0.70：集成达到（argmax 口径：验证 0.705，测试 0.727）。
- **中性类仍是瓶颈：**
  - 集成在验证集上的中性 F1 为 0.528（BERT 为 0.465），真实中性样本的错误率仍有 49%。
  - 0 < |y| ≤ 0.5 的样本错误率约 41%；|y| > 1 的样本错误率只有 3–6%。
- **优势来自文本理解：**
  - 只删文本时，DeBERTa 相对 BERT 的优势随缺失增大而消失：测试集在 10% 缺失时 +3.2 个点，50% 时 +1.3，90% 时 +0.6，100% 时约为 0。
  - 声学、视觉无论缺多少，对所有模型都几乎没有影响。
- **不同集成方式：** BERT 与 DeBERTa 的混合集成不如纯 DeBERTa 集成（验证宏 F1 0.662 对 0.686）。

## 二、v2 结论补验（只推理，不重训被审查的模型）

### 1. 90% 文本缺失：大部分收益来自“用缺失样本训练”，而不是 MG 结构

以下是与 base 的差，单位为宏 F1 百分点，括号内为视频区间。

| | 测试 | 验证 |
|---|---|---|
| mg（v1 门控） | +5.9 [4.2, 7.6]，5/5 个种子为正 | +8.0 [6.2, 9.6]，5/5 |
| joint（常规缺失增广训练） | +4.7 [3.6, 5.8]，5/5 | +4.9 [3.4, 6.2]，4/5 |
| mg2（单调门控） | +2.2，2/5（种子区间跨 0） | +2.6，2/5 |

- 从这两行估算，MG 结构在 joint 之上只多出约 1–3 个点。
- 它独有的优势是完整路径逐位不变：joint 在无原生缺失的样本上与 base 相差很大，最大 |Δp| 约 0.5。

### 2. “残余语义作支点”的假设不成立

- 按剩余“含字母或数字的整词”数分层，收益并不随剩余词数增加：
  - 测试集 mg：剩 1 个词 +9.7，2 个 +5.0，3–4 个 +4.2，≥5 个 +8.0；
  - 验证集：+11.0、+7.8、+6.1、+8.3。
- 只剩标点、没有实词时，base 的宏 F1 只有 0.11–0.15，低于随机猜测；而文本整段缺失（100%）时，谁都没有收益。
- 更符合数据的解释：base 对“几乎为空但不为零”的文本表示会系统性误判（分布外）。用缺失样本训练，主要纠正的是这种误判，而不是利用残余语义。

### 3. 原生缺失子集

- 这部分样本的原生缺失都在视觉上：验证 85 条，测试 99 条。
- mg 的门控在这些样本上全部被触发，平均 g 约 0.55。
- 类别改变 0–6 条（验证）、0–4 条（测试）；MAE 变化在 −0.8 到 +1.5 个百分点之间，影响很小。
- mg2 中选了 epoch 0 的种子完全不变。

### 4. 命题 3

- 自相关从估到滞后 8 改为估到滞后 20 后，50% 连续缺失的“理论值 / 实测值”比例由约 0.7 升到约 0.9（文本 0.74→0.90，声学 0.69→0.87，视觉 0.68→0.88）。
- 所以理论值偏低，主要来自自相关截断。

### 5. 共形预测（只在 VC 上校准，部署模型为 DeBERTa 集成）

- 目标 90%，强度区间的测试覆盖为：

| 桶 | 覆盖 | 视频区间 |
|---|---|---|
| 完整 | 0.880 | [0.845, 0.910] |
| 轻度 | 0.868 | [0.844, 0.891] |
| 中度 | 0.858 | [0.836, 0.878] |
| 重度 | 0.878 | [0.858, 0.897] |

- 极性集合覆盖为 0.885 / 0.892 / 0.880 / 0.917；单元素集合比例为 58% / 53% / 48% / 28%。
- **原因分析：**
  - VC 没有参与 DeBERTa 的任何选择，所以“校准数据被重复使用”这个解释可以排除。
  - 所有模型的测试 MAE 都高于验证 MAE（例如集成：VC 0.472，测试 0.538）。这与“验证集与测试集之间存在分布差异”一致，但不能当作证明。

### 6. 问题三

- **部署模型没有门控：** “内容效应”和“系统总效应”是同一个量。
- **删除检验：** 删高分位置与删随机位置的概率下降差（10% 预算）为：
  - 文本 +0.140 [0.102, 0.183]；
  - 声学 +0.002 [−0.001, 0.007]；
  - 视觉 0.000 [−0.002, 0.002]。

  声学、视觉的 |Δp| 超过 0.05 的样本只占约 1%。
- **主导模态：** 验证集中文本主导的样本占 95.6%。
- **稳定性（Spearman）：** 文本 0.999，声学 0.95，视觉 0.88。

### 7. 附件4：对齐置信度独立识别出了人工发现的不匹配样本

- Q3-15 的对齐得分只有 0.416，而打乱词序后的零假设得分为 0.386，两者只差 0.03。
- 其余 19 条的得分在 0.62–0.98 之间，且都比零假设高 0.2 以上。
- 事先写好的自动规则也会把 Q3-15 标为可疑，和人工核验结论一致。
- 能从附件2 找回的 5 条（都在测试集）极性 5/5 全对。这只作重叠案例检查。

## 三、v3 输出里发现的问题（v3.1 必须修）

1. **极性与强度不一致，违反题面定义：**
   - 部署集成的规则层选择了“只用决策层、不校准”。而 v2 的规则逻辑只在启用校准时才考虑一致化，所以一致化没有执行。
   - 结果是附件3 有 2 条“负向”却给出正强度（3_17：+0.063，3_30：+0.138）；所有“中性”预测的强度都不为 0（如 3_02：0.028）。附件4 的 13 号也是“中性”，强度 0.079。
   - 改法：最终输出一律强制一致化（这是题面定义，不是可选规则）；指标同时报告原始输出与一致化后的结果。
2. **附件3 的输入不一致（已证实）：** 训练集有 3392/3395 条用原文恢复了大小写，附件3 的 30 条则全部是小写还原文本。v3 在附件3 上的预测受到多大影响无法直接评估。改法：只从 `text_bert` 还原文本并重训。
3. **体积：** 5 种子集成交不上去（每个种子 fp32 29 MB）。可部署的是单模型（fp16 约 14.6 MB），或者集成蒸馏出的学生模型。
4. **文本证据里仍有虚词**（如 “a | of | video”）：宽度 3 的遮挡窗口会把重要词的得分摊给左右邻居。改法：文本改为逐个整词遮挡。
5. **选 epoch 噪声大：** VS 只有 332 条，相邻 epoch 的 F1 能差 ±3 个点；训练损失一直在下降，VS 的峰值却出现在第 2–7 个 epoch。可以考虑 LoRA 权重的指数滑动平均，再配合更少的 epoch。
6. **部分种子过度自信：** DeBERTa 单模型在验证集上的 ECE 为 0.04–0.23（s71 最高，集成 0.09），可以在 VS 上做温度缩放。
