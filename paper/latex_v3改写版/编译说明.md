# 编译说明（v3 改写版）

1. 把模板自带的 5 个字体文件（SimSun.ttf、simkai.ttf、STXinwei.ttf、LiSu.ttf、STFangsong.ttf）放到本文件夹。
2. 编译顺序：xelatex main → bibtex main → xelatex main → xelatex main。
3. 附录 A、B、C 的表由 `python tools/make_app_tables.py` 从 data/ 下的 CSV 生成（数值照抄原稿附录）；改了 CSV 后重跑一次即可。
4. 新增的两张图（缺失规律图、专项推理概览图）由 `python figures/make_charts_v3.py` 生成，数字取自原稿表 13 和附录 B、C。
